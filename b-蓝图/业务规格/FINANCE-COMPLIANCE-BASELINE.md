# 财务合规基线

> 本文档是 TMS 财务模块设计的"宪法"——所有财务业务规格（BS-05~08）必须符合本文档的要求。
> finance-ba 在输出每份财务规格前，必须逐条对照本文档进行自检。

## 二、旅行社行业特殊准则

### 2.1 旅游服务收入确认（CAS 14 应用）

```
关键判断：旅行社是"主要责任人"还是"代理人"？

主要责任人（总额法确认收入）：
  - 旅行社自行安排行程、承担服务质量责任
  - 自行定价、选择供应商
  → 全额确认收入，供应商费用计入成本

代理人（净额法确认收入）：
  - 仅为游客与供应商之间牵线搭桥
  - 不承担服务质量责任
  → 仅确认佣金/差价收入

TMS 必须支持两种模式：
  - 地接团队（DT）→ 通常为代理人 → 净额法
  - 组团团队（DTO/ZT）→ 通常为主要责任人 → 总额法
  - 代订项目（DD）→ 代理人 → 净额法
```

### 2.2 旅游服务增值税差额征税

```
依据：财税[2016]36号 附件2

可扣除项目（差额征税）：
  ✅ 支付给其他单位或个人的住宿费
  ✅ 支付给其他单位或个人的餐饮费
  ✅ 支付给其他单位或个人的交通费
  ✅ 支付给其他单位或个人的门票费
  ✅ 支付给其他接团旅游企业的旅游费（地接费）
  ✅ 签证费

不可扣除项目：
  ❌ 导游服务费
  ❌ 购物佣金
  ❌ 保险费
  ❌ 自身发生的差旅费

TMS 要求：
  - 成本科目必须区分"可差额扣除"和"不可差额扣除"
  - 发票管理必须对应扣除项目留存合规发票
  - 增值税申报表自动归集可扣除金额
```

### 2.3 佣金和分成的税务处理

```
导游分成：
  - 属于劳务报酬 → 旅行社代扣代缴个税（20%-40%累进）
  - 需要取得导游提供的劳务发票或由旅行社代开
  - 单次超过 800 元需预扣预缴

购物店返佣：
  - 属于旅行社的经营收入 → 需开具发票、缴纳增值税
  - 返给导游/司陪的部分 → 属于个人所得 → 代扣代缴个税
  - 不能在税前直接冲减成本

同业返佣：
  - 属于商业折扣 → 需在同一张发票上注明
  - 或单独签订佣金协议 → 取得对方发票
```

## 三、财务合规检查清单

每份财务规格输出前，finance-ba 必须逐条检查以下项目：

### 3.1 会计处理合规性

- [ ] **收入确认方法**：是否正确区分总额法/净额法？是否标注了每个业务模式的适用方法？
- [ ] **会计分录**：借贷方向是否正确？是否符合复式记账原则？
- [ ] **科目设置**：科目编码是否符合《企业会计准则——应用指南》科目表？
- [ ] **成本归集**：成本项目分类是否完整？是否区分可扣除/不可扣除？
- [ ] **收入成本配比**：收入确认时点与成本归集时点是否匹配（一团一核算）？
- [ ] **坏账计提**：应收账款是否设计了减值测试机制？

### 3.2 税务合规性

- [ ] **增值税**：是否标注了差额征税可扣除项目？是否设计了发票归集功能？
- [ ] **所得税**：成本费用是否有合规票据支撑？是否有票据管理流程？
- [ ] **个税**：导游分成/司陪分成是否设计了代扣代缴机制？
- [ ] **印花税**：合同签单是否考虑了印花税计算？

### 3.3 内控合规性

- [ ] **不相容职务分离**：
  - 出纳 ≠ 记账（收付款人和记账人不能是同一人）
  - 审批 ≠ 执行（审批人和执行人不能是同一人）
  - 制单 ≠ 复核（制单人和复核人不能是同一人）
- [ ] **授权审批**：是否设计了分级审批权限？金额阈值是否合理？
- [ ] **会计凭证**：每笔收付款是否都有原始凭证关联？
- [ ] **对账机制**：是否设计了银行对账、往来对账、内部对账？
- [ ] **审计轨迹**：是否所有财务操作都有不可篡改的操作日志？

### 3.4 旅行社行业特殊要求

- [ ] **一团一核算**：每个团是否能独立出利润表？
- [ ] **代收代付**：代收款项是否与自营收入分开核算？
- [ ] **预收预付**：预收团款、预付地接款的账龄分析是否可行？
- [ ] **外币业务**：是否支持多币种？汇兑损益如何处理？
- [ ] **关联交易**：集团内部公司间交易是否有独立的定价和审批机制？

## 四、Odoo 会计模块合规映射

### 4.1 Odoo 标准会计功能（必须使用）

| Odoo 功能 | 合规要求 | 说明 |
|-----------|---------|------|
| account.move | 复式记账 | 所有分录必须借贷平衡 |
| account.payment | 收付款 | 关联银行对账单 |
| account.reconcile | 对账 | 银行对账、往来对账 |
| account.tax | 税金 | 增值税自动计算 |
| account.fiscal.position | 财税映射 | 不同业务的税率映射 |
| account.analytic | 分析会计 | 一团一核算的分析维度 |

### 4.2 TMS 自定义会计功能（必须遵循准则）

| 自定义功能 | 准则依据 | 合规检查点 |
|-----------|---------|-----------|
| 单团利润表 | CAS 30 | 格式是否符合报表列报要求 |
| 佣金分成计算 | CAS 9 + 个税法 | 是否正确代扣代缴 |
| 差额征税归集 | 财税[2016]36号 | 可扣除项目是否准确 |
| 收款认领 | 内控规范 | 不相容职务是否分离 |
| 审批流程 | 内控规范 | 授权审批矩阵是否完整 |

## 五、合规审查流程

```
finance-ba 输出财务规格
    ↓
自检：逐条过合规检查清单（第三节）
    ↓
标注：每个业务规则的准则依据
    ↓
交付给 项目协调人
    ↓
协调人交叉验证：
  - 检查自检清单是否全部通过
  - 抽查关键业务规则的准则依据
  - 识别潜在合规风险
    ↓
通过 → 交付给 dev-odoo
未通过 → 退回 finance-ba 修改
```

### 5.1 合规标记规范

每份财务规格中的每条业务规则，必须标注：

```
[准则依据] 规则描述

示例：
[CAS 14-代理人] 地接团队（DT模式）采用净额法确认收入，
  仅确认差价/佣金收入，地接费用不计入旅行社收入。

[财税2016-36号] 住宿费、餐饮费、交通费、门票费、地接费
  可从增值税计税依据中扣除，需取得合规发票。

[内控-职务分离] 收款认领操作：登记人 ≠ 认领人 ≠ 审核人，
  三个角色必须由不同人员担任。

[个税法-劳务报酬] 导游分成收入按劳务报酬所得代扣代缴个税，
  单次超过800元需预扣预缴，税率20%-40%累进。
```

## 六、已知合规风险点

以下是 TMS 财务模块中已识别的高风险合规点，finance-ba 在编写规格时需特别关注：

| 风险点 | 风险等级 | 说明 | 缓解措施 |
|--------|---------|------|---------|
| 总额法/净额法判断错误 | 🔴 高 | 收入确认方式错误导致税务风险 | 每个业务模式明确标注适用方法 |
| 差额征税扣除不合规 | 🔴 高 | 扣除项目无合规发票，被税务局追缴 | 成本发票管理模块，逐笔关联 |
| 导游分成未代扣个税 | 🔴 高 | 未履行代扣代缴义务，罚款+滞纳金 | 分成发放前自动计算预扣税额 |
| 不相容职务未分离 | 🟡 中 | 内控缺陷，资金安全风险 | 系统级权限控制，强制角色分离 |
| 关联交易定价不合理 | 🟡 中 | 转移定价被税务调整 | 关联交易独立定价规则 |
| 预收团款长期挂账 | 🟡 中 | 未及时确认收入，少缴税款 | 账龄预警，超期自动提醒 |
| 外币汇兑损益处理 | 🟢 低 | 汇兑损益计算不准确 | 按准则规定月末调整 |
