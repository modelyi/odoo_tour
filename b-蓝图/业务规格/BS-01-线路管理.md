# BS-01-线路管理

> 编写人：tour-ba
> 版本：v1.0
> 日期：2026-09-12

## 1. 业务背景

线路产品是旅行社的核心商品，贯穿「产品设计 → 上架发布 → 销售报价 → 计调执行 → 财务核算」全链路。当前海螺旅行社在易途系统中维护了 **85 个线路分类** 和 **212 条线路模板**（含 82 个字段），覆盖品质纯玩/深度、常规、自由行、代订等多种类型。

业务痛点：
- 线路分类层级混乱（最多支持 3 层 ParentID），查找效率低
- 线路模板字段过多（82 个），实际填写率不足 30%，大量冗余
- 发团计划与线路模板耦合，无法灵活设置余位和同行价
- 线路缺少审核发布流程，编辑即生效

## 3. 业务流程

### 3.1 线路创建与发布流程

```
创建线路分类（树形）
    ↓
创建线路模板（选择分类、填写基本信息、行程安排、价格）
    ↓
上传附件（行程PDF、合同模板）
    ↓
设置线路标签/特色/推荐
    ↓
提交审核
    ↓
审核通过 → 启用（UseChk=1）
    ↓
创建发团计划（设置日期、余位、同行价）
    ↓
发布给同业 / 门市可见
```

### 3.2 发团计划管理流程

```
选择线路模板
    ↓
设置发团日期（BeginDate~EndDate）
    ↓
设置各类型价格（成人/儿童/老人/婴儿/学生）
    ↓
设置余位数（PlanNum）
    ↓
设置同行价（同行分销专用）
    ↓
发布 → 零售商/门市可查询
    ↓
客人报名 → 余位自动递减
    ↓
发团完成 → 自动归档
```

## 4. 功能需求

### 4.1 线路分类管理

| 功能 | 说明 | 业务规则 |
|------|------|----------|
| 分类树 CRUD | 支持最多 3 层分类（ParentID 递归） | 删除父分类时需先删除/移动子分类 |
| 分类启用/停用 | UseChk 字段控制 | 停用分类下所有线路自动隐藏 |
| 分类排序 | OrderNum 字段 | 同层级按 OrderNum 升序排列 |
| 分类价格 | BasePrice、Price 字段 | 可作为该分类下线路的默认参考价 |

### 4.2 线路模板管理

| 功能 | 说明 | 业务规则 |
|------|------|----------|
| 线路 CRUD | 82 字段完整表单 | LineCode 可自动生成（AutoBuildLineCode） |
| 多类型价格 | AdultPrice、ChildPrice、OldManPrice、BabyPrice、StudentPrice | 价格 ≥ 0，儿童价 ≤ 成人价 |
| 行程天数 | DayNum（1~30 天，系统参数限制） | ValidDayNum 控制线路有效期 |
| 出发/目的地 | SendPlace、EndPlace + FromProvince/City、ToProvince/City | 支持省市区三级联动 |
| 费用说明 | FeeInclude、FeeExclude | 富文本格式 |
| 行程详情 | SrvText（行程安排）、LineDetailsRich（富文本） | 按天编写（第1天、第2天…） |
| 购物信息 | ShoppingInfo | 记录购物店名称和停留时间 |
| 自费项目 | SelfPaidItem | 如"三轮车90/四合院30/恭王府70" |
| 导游分成 | Guide_ShareRate、Guide_Premium | 百分比 + 固定金额 |
| 线路附件 | LineAttachmentList、AttachFileName/GuidID | 支持多文件上传 |
| 审核流程 | AuditChk、AuditChk_UserName、AuditChk_Date | 未审核线路不可被订单引用 |
| 启用/停用 | UseChk | 停用后已有订单不受影响，但不可新建 |
| 助记码 | HelpCode | 拼音首字母，辅助快速检索 |
| 特殊标记 | IsSpecial、IsJw（境外）、IsDJS（地接社）、LineKind、LineCamp | 控制线路业务属性 |

### 4.3 发团计划管理

| 功能 | 说明 | 业务规则 |
|------|------|----------|
| 创建计划 | 基于线路模板 + 出发日期创建 | 同一线路同日期可创建多个计划 |
| 余位管理 | PlanNum（总位数）→ 报名自动递减 | 余位为 0 时自动关闭报名 |
| 同行价 | 独立于门市价，面向分销渠道 | 仅同行（TH）来源订单可见 |
| 计划状态 | 未开始 / 报名中 / 已成团 / 已满 / 已取消 / 已完成 | 出发日期过后自动转"已完成" |
| 批量操作 | 批量创建连续日期计划 | 支持按周/隔日批量生成 |

### 4.4 核心业务规则汇总

1. **编号规则**：LineCode 支持自动生成，格式可由系统参数配置
2. **最大行程天数**：30 天（系统参数控制）
3. **价格校验**：各类型价格必须 ≥ 0；儿童价不得高于成人价
4. **分类约束**：每条线路必须归属一个末级分类
5. **审核约束**：未审核线路（AuditChk=0）不可创建发团计划
6. **并发控制**：同一操作员同一时间最多打开 20 个标签页（系统参数）

## 7. 与易途系统对标

| 易途功能 | 菜单入口 | 本系统实现方式 |
|----------|----------|----------------|
| 线路分类（85条） | 资源中心>线路分类 | tour.line_type 模型，树形结构 |
| 线路模板（212条/82字段） | 资源中心>线路模板 | tour.line 模型，精简为 ~50 核心字段 |
| 散客团期计划 | 散客计划>团期计划 | tour.departure_plan 模型 |
| 线路审核 | 隐含在 AuditChk 字段 | 显式审核工作流 |
| 线路附件 | LineAttachmentList | ir.attachment 关联 |
| 助记码检索 | HelpCode 字段 | 拼音首字母自动计算 + 前端搜索 |
| 自动生成编号 | AutoBuildLineCode | 序列配置 |
