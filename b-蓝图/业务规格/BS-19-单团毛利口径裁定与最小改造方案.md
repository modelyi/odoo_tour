## 一、结论先行（拍板）

### 1.1 问题定性

`tour.plan.account.profit` 现行公式 `income_total − cost_total` 把**两个不同口径**相减：

| 侧 | 字段 | 口径 | 实测合计 |
|----|------|------|---------:|
| 收入 | `income_total` | **不含税**（已按 BS-11 §7.1 价税分离后入 6001.0x） | 237,920,274.46 |
| 成本 | `cost_total` | **含税**（供应商账单 `tax_ids=[]`，未拆进项；6401 全额入账） | 255,726,307.91 |
| 结果 | `profit` | **混口径** | **−17,806,033.45** |

> **live DB 实证**（2026-09-14，`tms-db` / 库 `tms`）：
> - `6001.01 + 6001.03 = 237,192,858.78`（贷，不含税）；`2221.01 = 14,231,565.93`（贷）≈ Σ6001 × 6% → **收入侧确已拆税**；
> - `6401 = 255,420,259.84`（借）；`account_move_line` 中 6401 全部 86,138 行 `tax_line_id` / `tax_base_amount` 均为空 → **成本侧确未拆税**。
> - **不对称成立，−17.8M 不是经营亏损，是口径差。**

### 1.2 拍板结论

**【裁定 1】收入侧口径不动。** `income_total` = 不含税收入，符合 [CAS 14-价税分离] 与 BS-11 §7.1，任何情况下不得改回含税。

**【裁定 2】成本侧在台账层做不含税换算，`profit` 采用「差额征税·不含税口径」。** 成本的不含税化按**本企业税率 r**（财会〔2016〕22 号：差额征税抵减按本企业税率、用可扣除项目含税金额统一计算，不分项换算供应商税率）：

```
cost_net_total = cost_total ÷ (1 + r)
profit         = income_total − cost_net_total
```

等价写法（与任务推导一致）：`profit =（含税收入 − 含税成本）÷ (1 + r)`。
验证：团 7372（`AQL-210507T-1`，biz_mode 1，含税报价 472,279）→ `445,546.23 − (含税成本 ÷1.06)`，与 `(含税收入 − 含税成本) ÷1.06` 恒等。

**【裁定 3】保留含税口径，但只作管理/业务口径，单列字段。** 新增 `profit_tax_incl`（含税毛利）= 含税收入 − 含税成本，用于与源系统 `in_com_quo_sum − out_sum` 及业务报价核对。**`profit` 是唯一权威利润字段。**

**【裁定 4】净额法（biz_mode 41 代订 / 6001.02 地接）无需特判**，同式自动成立：代收代付走 2241.01 不进 6401 → `cost_total = 0` → `profit = income_total`（= 差价不含税）。差额征税**不适用**净额法（税基即差价，无可扣除环节，[BS-11 §九]）。

**【裁定 5】确立不变量，杜绝双重扣减。** `cost_total` 的语义固定为**成本分析行净额**（含税，含 BS-14 §5.3 代订成本转出等业务冲销，**不含**差额抵减回写）。若 BS-11 §7.2.2 差额抵减凭证回写 6401（财会 22 号标准分录），则 6401 已成净额，台账**必须关闭**不含税换算，改回 `cost_net_total = cost_total`。两种状态由**一个公司级开关** `tour_cost_tax_split` 唯一决定，不得叠加：

| `res.company.tour_cost_tax_split` | 含义 | 台账口径 |
|:---:|------|---------|
| `False`（**默认，现行**） | 记账侧未拆成本税（成本全额含税入 6401） | `cost_net_total = cost_total ÷ (1+r)` |
| `True`（未来：成本分项 + 抵减凭证落地） | 记账侧已拆税（6401 为不含税净额） | `cost_net_total = cost_total` |

## 二、唯一正确公式（可抄进代码）

### 2.1 符号

| 符号 | 含义 | 来源 |
|------|------|------|
| `r` | 本企业税率/征收率（一般 6% / 小规模 3%(1%)）÷100 | `_tour_vat_params()` [BS-11 §10.3] |
| `income_total` | 不含税收入 | 分析行 income 类科目汇总 |
| `cost_total` | 含税成本（成本分析行净额） | 分析行 expense 类科目汇总 |
| `income_commission` | 购物佣金收入（经营收入，不可差额扣除） | 台账直填 |

### 2.2 公式（三种业务情形全覆盖）

| 情形 | biz_mode | 公式 |
|------|----------|------|
| **总额法 · 差额征税启用**（现行默认） | 1 / 12 / 13 / 14 / 15 / 21 / 31 | `profit = income_total − cost_total ÷ (1+r)` |
| **总额法 · 全额征税**（`tour_diff_tax_enabled=False`，走进项抵扣） | 同上 | `profit = income_total − (cost_total − 进项税额)`；进项税额自 2221.02 归集，当前无进项数据时以 `÷(1+r)` 近似并标注 |
| **净额法 · 代订/地接**（代理人，无差额扣除） | 41（代订）/ 6001.02（地接，当前空置） | `profit = income_total − 0 = income_total`（差价不含税），同式自动成立 |

### 2.3 代码（替换 `tour_accounting/models/tour_plan_account.py`）

```python
    # === 单团毛利口径（BS-19 裁定：差额征税·不含税口径）===
    cost_net_total = fields.Float(
        '不含税成本', digits=(16, 2), compute='_compute_profit', store=True,
        help='= 成本合计 ÷(1+r)，差额征税不含税化 [BS-19 §二 / 财会2016-22号]')
    profit = fields.Float(
        '毛利(不含税)', digits=(16, 2), compute='_compute_profit', store=True,
        help='= 不含税收入 − 不含税成本（唯一权威口径）[CAS 14 / CAS 30 / BS-19]')
    profit_no_shop = fields.Float(
        '毛利(不含税,不含购物)', digits=(16, 2), compute='_compute_profit', store=True,
        help='= (不含税收入 − 购物佣金收入) − 不含税成本')
    profit_tax_incl = fields.Float(
        '毛利(含税口径)', digits=(16, 2), compute='_compute_profit', store=True,
        help='= 含税收入 − 含税成本，业务/源系统可核对口径，非权威利润 [BS-19 §一 裁定3]')

    @api.depends('income_total', 'cost_total', 'income_commission',
                 'company_id.tour_taxpayer_type', 'company_id.tour_vat_rate',
                 'company_id.tour_vat_levy_rate', 'company_id.tour_cost_tax_split')
    def _compute_profit(self):
        """单团毛利：差额征税·不含税口径，收入/成本同口径相减 [BS-19 §二]。

        - 总额法（组团）：成本按本企业税率 r 不含税化 → 与不含税收入配比
        - 净额法（代订 41 / 地接）：cost_total=0（代收代付走 2241.01），profit=差价不含税
        不变量：cost_total 为成本分析行净额（含税）；若记账侧已拆成本税
        （tour_cost_tax_split=True），则不再换算，避免双重扣减。
        """
        for rec in self:
            co = rec.company_id or self.env.company
            rate = (co.tour_vat_rate if co.tour_taxpayer_type == 'general'
                    else co.tour_vat_levy_rate) or 0.0
            rr = rate / 100.0
            gross = rec.cost_total or 0.0
            cost_net = round(gross, 2) if co.tour_cost_tax_split or not rr \
                else round(gross / (1 + rr), 2)
            rec.cost_net_total = cost_net
            rec.profit = round((rec.income_total or 0.0) - cost_net, 2)
            rec.profit_no_shop = round(
                (rec.income_total or 0.0) - (rec.income_commission or 0.0) - cost_net, 2)
            inc_gross = (rec.income_total or 0.0) * (1 + rr) if rr \
                else (rec.income_total or 0.0)
            rec.profit_tax_incl = round(inc_gross - gross, 2)
```

> **取值修正**：原 `_compute_profit` 无税率依赖，新公式须用 `rec.company_id`（而非 `self.env.company`）取税参数，保证多主体（5 主体各自身份/税率）正确 [BS-16 §一]。

## 三、字段改动清单

**新增 3 个 / 修改 2 个 / 新增配置 1 个，全部 `store=True` 以保证 pivot 聚合走本表列（不跨表实时连接）。**
