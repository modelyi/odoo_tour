## 1. 业务背景

购物佣金是地接旅行社的重要收入来源之一。海螺旅行社在易途系统中建立了完整的购物佣金管理体系，涵盖购物数据录入、佣金计算、多层分成（旅行社/导游/司陪）、购物协议、人均线考核等全流程。

**合规重点（高风险区域）**：

1. [增值税暂行条例] 购物店返佣属于旅行社的经营收入，需开具发票、缴纳增值税，**不能直接冲减成本**
2. [个税法-劳务报酬] 导游分成属于劳务报酬所得，旅行社必须**代扣代缴个税**（20%-40% 累进税率），单次超过 800 元需预扣预缴
3. [CAS 9-职工薪酬] 需明确导游分成属于劳务报酬（非工资薪金），按劳务关系处理
4. [CAS 14-收入确认] 佣金收入按总额法确认（旅行社为主要责任人），分成支出作为成本费用
5. [内控-审计轨迹] 佣金计算和分成支付全流程必须有不可篡改的操作日志

系统菜单结构（2.9 购物管理、2.21 购物协议）提供了 20+ 个购物相关功能入口，覆盖数据录入、查询统计、协议管理、佣金计算等全链路。

## 3. 财务流程

### 3.1 购物佣金计算流程（含个税代扣代缴）

```
【步骤1：购物数据录入】导游/计调
  ↓ 导游通过 APP 实时录入（菜单 [3346]）
  ↓ 计调在系统中补录/修改（菜单 [3346][4303][4304]）
  ↓ 数据关联：团队(PlanCode) + 购物店(SupplierID) + 金额
  ↓ [内控-审计轨迹] 记录：录入人、录入时间、数据来源

【步骤2：购物成本录入】计调（菜单 [4305]）
  ↓ 录入购物相关成本（如回扣、礼品等）
  ↓ 用于计算净利润
  ↓ [增值税暂行条例] 购物成本不可从增值税计税依据中扣除

【步骤3：佣金自动计算】系统
  ↓ 根据购物协议（菜单 [3599][3850]）确定返佣比例
  ↓ 根据司陪导协议（菜单 [3851]）确定分成比例
  ↓ 根据人均线（菜单 [3852][3853]）调整分成
  ↓ [CAS 14-总额法] 佣金按总额法确认收入（旅行社为主要责任人）
  ↓ 计算各层分成金额

【步骤4：个税代扣代缴计算】系统 [个税法-劳务报酬]
  ↓ 导游分成 = 导游分成金额（税前）
  ↓ 计算预扣个税：
     - 单次 ≤ 800 元：不预扣
     - 800 < 单次 ≤ 4000 元：预扣 = (单次 - 800) × 20%
     - 单次 > 4000 元：预扣 = 单次 × (1-20%) × 适用税率 - 速算扣除数
       - ≤ 20000 元：20%，速算扣除数 0
       - 20000-50000 元：30%，速算扣除数 2000
       - > 50000 元：40%，速算扣除数 7000
  ↓ 导游实发 = 导游分成 - 预扣个税
  ↓ [内控-审计轨迹] 记录：计算过程、适用税率、速算扣除数

【步骤5：佣金确认】会计
  ↓ 审核佣金计算结果
  ↓ 确认应收佣金（购物店应付）→ 经营收入
  ↓ 确认应付分成（导游/司陪应得）→ 劳务成本
  ↓ 确认应付个税（代扣代缴）→ 应交税费

【步骤6：佣金收款】出纳
  ↓ 与购物店对账（菜单 [4316]）
  ↓ [增值税暂行条例] 开具增值税发票给购物店
  ↓ 收款入账
  ↓ 核销应收佣金

【步骤7：分成支付（含代扣代缴）】出纳
  ↓ 支付导游实发金额（税后）
  ↓ [个税法-代扣代缴] 次月 15 日前申报缴纳代扣个税
  ↓ 支付司陪分成（同样代扣代缴个税）
  ↓ 核销应付分成
  ↓ [内控-审计轨迹] 记录：支付时间、支付金额、代扣税额
```

### 3.2 多层分成模型（含个税代扣）

```
购物总额（客人实际消费）
  ↓
× 购物店返佣比例（购物协议）
  ↓
= 佣金总额（购物店应付给旅行社）[增值税暂行条例-经营收入]
  ↓
├── 旅行社留存（公司利润）= 佣金总额 - 导游税前分成 - 司陪税前分成
├── 导游税前分成（Guide_ShareRate）
│    ├── 预扣个税 [个税法-劳务报酬]
│    └── 导游实发 = 税前分成 - 预扣个税
├── 司机税前分成（如有）
│    ├── 预扣个税 [个税法-劳务报酬]
│    └── 司机实发 = 税前分成 - 预扣个税
└── 陪同税前分成（如有）
     ├── 预扣个税 [个税法-劳务报酬]
     └── 陪同实发 = 税前分成 - 预扣个税
```

[CAS 9-职工薪酬] 导游/司机/陪同与旅行社之间为劳务关系（非雇佣关系），分成收入按"劳务报酬所得"代扣代缴个税，不计入工资薪金。如导游为旅行社正式员工（签订劳动合同），则按"工资薪金"代扣代缴。系统需支持两种模式配置。

### 3.3 人均线考核机制

人均线是指团队人均购物金额的考核标准，影响导游分成比例和奖金。

```
【人均线计算】
人均购物 = 团队购物总额 / 客人数(GuestCount)

【人均线等级】
- 低于基础线：基础分成比例
- 达到基础线：标准分成比例
- 达到优秀线：提高分成比例 + 奖金(Guide_Premium)

【人均算法设置】（菜单 [3853]）
- 可配置不同线路/购物店的人均线标准
- 可配置分成比例的阶梯规则
```

[个税法-劳务报酬] 奖金（Guide_Premium）同样属于劳务报酬所得，需合并到当次分成中一起计算预扣个税。

### 3.4 购物退单/补单流程

```
【购物退单】（菜单 [4303]）
  ↓ 客人退货或投诉
  ↓ 冲减购物金额
  ↓ 重新计算佣金和分成
  ↓ [增值税暂行条例] 如已开票，需开具红字发票冲减收入
  ↓ [个税法] 如已代扣个税，需在下次代扣时抵扣或申请退税

【购物补单】（菜单 [4304]）
  ↓ 漏录或延迟确认的购物
  ↓ 补充购物记录
  ↓ 重新计算佣金和分成
  ↓ [内控-授权审批] 补单需审核（防止虚报）
```

| 字段 | 类型 | 说明 |
|------|------|------|
| item_name | Char | 商品名称 |
| quantity | Integer | 数量 |
| unit_price | Decimal | 单价 |
| amount | Decimal | 金额 |

#### 业务规则

1. **数据录入**：
   - 导游通过 APP 实时录入（source='APP'）
   - 计调在系统中补录（source='系统'）

   - guest_count ≤ 团队 GuestCount

   - per_capita = total_amount / guest_count
   - 四舍五入到分

3. **状态流转**：
   - 待确认 → 已确认（会计审核）
   - 已确认 → 已退单（退单操作）

4. [内控-审计轨迹] 所有录入/修改操作记录操作人、时间、变更内容

- **劳务报酬**（默认）：导游/司机/陪同与旅行社为劳务关系，按 20%-40% 累进税率代扣代缴
- **工资薪金**：如为旅行社正式员工（签订劳动合同），按 3%-45% 累进税率代扣代缴，并入月度综合所得

#### 奖金规则明细

| 字段 | 类型 | 说明 | 合规标注 |
|------|------|------|----------|

[个税法-劳务报酬] 奖金属于劳务报酬所得的一部分，需合并到当次分成中计算预扣个税。

#### 业务规则

1. 分成比例 + 旅行社留存 = 100%
2. 奖金在达到人均线后额外发放
3. 导游档案中有 Guide_ShareRate（默认分成比例）和 Guide_Premium（默认奖金）
4. [个税法-代扣代缴] 分成发放前系统自动计算预扣税额

### 4.8 人均算法设置（菜单 [3853]）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer | 算法ID |
| calc_mode | Selection | 计算方式(简单平均/加权平均/分段计算) |
| round_way | Selection | 取整方式(四舍五入/向上取整/向下取整) |
| decimal_places | Integer | 小数位数 |
| state | Selection | 生效/已失效 |

#### 业务规则

1. **简单平均**：per_capita = total_amount / guest_count
2. **加权平均**：按客人类型加权（成人=1，儿童=0.5，老人=0.8）
3. **分段计算**：不同购物店使用不同算法

### 4.9 佣金计算引擎（含个税代扣代缴）

#### 计算流程

```python
def calculate_commission(plan_id):
    # 1. 获取团队购物数据
    shop_records = get_shop_records(plan_id)
    total_amount = sum(r.total_amount for r in shop_records)
    guest_count = get_guest_count(plan_id)
    per_capita = total_amount / guest_count

    # 2. 按购物店分组计算
    shop_groups = group_by_shop(shop_records)
    commissions = []

    for shop_id, records in shop_groups.items():
        shop_amount = sum(r.total_amount for r in records)
        shop_per_capita = shop_amount / guest_count

        # 3. 查找购物协议
        agreement = get_shop_agreement(shop_id, plan_date)
        if not agreement:
            continue

        # 4. 计算返佣比例（阶梯规则）
        commission_rate = get_commission_rate(agreement, shop_per_capita)

        # 5. 计算佣金总额 [增值税暂行条例-经营收入]
        commission_total = shop_amount * commission_rate / 100

        # 6. 查找司陪导协议
        guide = get_guide(plan_id)
        guide_agreement = get_staff_agreement('导游', guide.id)
        guide_share_rate = guide_agreement.share_rate if guide_agreement else guide.Guide_ShareRate
        tax_type = guide_agreement.tax_type if guide_agreement else '劳务报酬'

        # 7. 计算导游税前分成
        guide_share_before_tax = commission_total * guide_share_rate / 100

        # 8. 检查人均线奖金
        base_line = get_base_line(plan_id, shop_id)
        excellent_line = get_excellent_line(plan_id, shop_id)

        premium = 0
        if shop_per_capita >= excellent_line:
            premium = guide_agreement.premium_amount if guide_agreement else guide.Guide_Premium

        # 9. 导游税前总收入 = 分成 + 奖金
        guide_total_before_tax = guide_share_before_tax + premium

        # 10. 计算代扣个税 [个税法-劳务报酬]
        if tax_type == '劳务报酬':
            guide_tax = calc_labor_tax(guide_total_before_tax)
        else:  # 工资薪金
            guide_tax = calc_salary_tax(guide_total_before_tax)

        # 11. 导游实发 = 税前 - 个税
        guide_net_pay = guide_total_before_tax - guide_tax

        # 12. 旅行社留存 = 佣金总额 - 导游税前分成 - 导游奖金
        company_retain = commission_total - guide_total_before_tax

        commissions.append({
            'shop_id': shop_id,
            'shop_amount': shop_amount,
            'commission_total': commission_total,        # 经营收入（含税）
            'guide_share_before_tax': guide_share_before_tax,  # 导游税前分成
            'premium': premium,                          # 导游奖金（税前）
            'guide_tax': guide_tax,                      # 代扣个税
            'guide_net_pay': guide_net_pay,              # 导游实发
            'company_retain': company_retain             # 旅行社留存
        })

    return commissions


def calc_labor_tax(amount):
    """
    劳务报酬预扣个税计算 [个税法-劳务报酬]
    - 单次 ≤ 800 元：不预扣
    - 800 < 单次 ≤ 4000 元：预扣 = (单次 - 800) × 20%
    - 单次 > 4000 元：预扣 = 单次 × (1-20%) × 适用税率 - 速算扣除数
    """
    if amount <= 800:
        return 0
    elif amount <= 4000:
        return (amount - 800) * 0.20
    else:
        taxable = amount * (1 - 0.20)
        if taxable <= 20000:
            return taxable * 0.20 - 0
        elif taxable <= 50000:
            return taxable * 0.30 - 2000
        else:
            return taxable * 0.40 - 7000
```

## 9. 合规自检清单

### 9.1 会计处理合规性

- [x] **收入确认方法**：佣金收入按总额法确认（旅行社为主要责任人），分成支出作为成本费用 → [CAS 14-总额法]
- [x] **会计分录**：所有分录借贷平衡，符合复式记账原则
- [x] **科目设置**：佣金收入计入 6051 其他业务收入，导服成本计入 6407，代扣个税计入 2221
- [x] **成本归集**：购物成本（回扣/礼品）单独归集，不可差额扣除 → [增值税暂行条例]
- [x] **收入成本配比**：佣金收入与导游分成在同一期间确认（一团一核算）

### 9.2 税务合规性

- [x] **增值税**：佣金收入按经营收入列报，自动计算销项税额，不可直接冲减成本 → [增值税暂行条例]
- [x] **个税代扣代缴**：
  - 导游分成按"劳务报酬所得"代扣代缴个税（20%-40% 累进） → [个税法-劳务报酬]
  - 单次超过 800 元需预扣预缴 → [个税法-预扣预缴]
  - 系统自动计算预扣税额，生成代扣代缴申报表 → [个税法-代扣代缴]
  - 奖金合并到当次分成中计算个税 → [个税法-劳务报酬]
- [x] **印花税**：购物返佣协议按合同缴纳印花税 → [印花税法]
- [x] **差额征税**：购物佣金不属于可扣除项目，导游服务费不属于可扣除项目 → [财税2016-36号]

### 9.3 内控合规性

- [x] **不相容职务分离**：
  - 购物数据录入人 ≠ 佣金确认人 → [内控-职务分离]
  - 退单/补单录入人 ≠ 审核人 → [内控-职务分离]
- [x] **授权审批**：退单/补单设计了审核流程 → [内控-授权审批]
- [x] **会计凭证**：佣金计算关联购物协议、司陪导协议，原始数据可追溯 → [内控-会计凭证]
- [x] **审计轨迹**：所有操作记录操作人、时间、变更内容 → [内控-审计轨迹]

### 9.4 旅行社行业特殊要求

- [x] **一团一核算**：佣金计算结果关联团队订单（PlanCode），支持单团利润查询
- [x] **CAS 9 职工薪酬分类**：司陪导协议明确标注税务类型（劳务报酬/工资薪金），系统根据类型自动选择个税计算方式
- [x] **公允价值确认**：佣金按购物协议约定的比例计算，反映公允价值 → [CAS 39]

## 11. 个税代扣代缴计算示例

### 示例 1：导游分成 500 元（≤ 800 元）

```
税前分成：500 元
预扣个税：0 元（≤ 800 元不预扣）
实发金额：500 元
```

### 示例 2：导游分成 3000 元（800 < x ≤ 4000）

```
税前分成：3000 元
预扣个税：(3000 - 800) × 20% = 440 元
实发金额：3000 - 440 = 2560 元
```

### 示例 3：导游分成 10000 元（> 4000 元，应纳税所得额 ≤ 20000）

```
税前分成：10000 元
应纳税所得额：10000 × (1 - 20%) = 8000 元
预扣个税：8000 × 20% = 1600 元
实发金额：10000 - 1600 = 8400 元
```

### 示例 4：导游分成 50000 元（应纳税所得额 20000-50000）

```
税前分成：50000 元
应纳税所得额：50000 × (1 - 20%) = 40000 元
预扣个税：40000 × 30% - 2000 = 10000 元
实发金额：50000 - 10000 = 40000 元
```

### 示例 5：导游分成 100000 元 + 奖金 5000 元（应纳税所得额 > 50000）

```
税前总收入：100000 + 5000 = 105000 元
应纳税所得额：105000 × (1 - 20%) = 84000 元
预扣个税：84000 × 40% - 7000 = 26600 元
实发金额：105000 - 26600 = 78400 元
```
