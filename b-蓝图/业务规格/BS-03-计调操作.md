# BS-03-计调操作

> 编写人：tour-ba
> 版本：v1.0
> 日期：2026-09-12

## 1. 业务背景

计调是旅行社的运营中枢，负责将已确认订单转化为可执行的行程安排。当前海螺旅行社在易途系统中的计调模块涵盖 **预订安排、导游安排、用房安排、用车安排、保险安排、地接安排** 6 大操作台，关联 **886 家酒店、240 家餐厅、337 个景区、137 家车辆公司、2,173 名导游** 等资源档案。

业务痛点：
- 资源预订分散在 6 个独立页面，计调需反复切换，容易遗漏
- 用房/用车/门票的预订确认状态缺少统一视图
- 导游安排与车辆安排缺乏冲突检测（同一导游/车辆同一天被重复安排）
- 成本录入与资源预订脱节，实际成本与预算差异难以实时跟踪
- 地接安排（委托下游地接社）缺少在线确认机制

## 3. 业务流程

### 3.1 计调操作总流程

```
订单确认（已确认状态）
    ↓
进入计调操作台（统一看板）
    ↓
┌─────────────────────────────────────────────┐
│  并行安排（可任意顺序）                         │
│  ├── 导游安排 → 选择导游 → 设置导服费 → 确认   │
│  ├── 用车安排 → 选择车辆 → 设置接送计划 → 确认  │
│  ├── 用房安排 → 选择酒店 → 设置房型间数 → 确认  │
│  ├── 用餐安排 → 选择餐厅 → 设置餐标人数 → 确认  │
│  ├── 门票预订 → 选择景区 → 设置票种人数 → 确认  │
│  ├── 保险安排 → 选择保险公司 → 设置保额 → 确认  │
│  └── 地接安排 → 选择地接社 → 发送确认函 → 确认  │
└─────────────────────────────────────────────┘
    ↓
资源预订确认（营运中心确认房/门票）
    ↓
出团通知书（自动生成，含导游/车辆/酒店/行程信息）
    ↓
导游借款（出发前）
    ↓
出团执行
    ↓
导游报账（回团后）
    ↓
成本录入（各项资源实际费用）
    ↓
计调审核 → 财务审核
    ↓
单团归档
```

### 3.2 导游安排流程

```
查看待派导团队列表
    ↓
选择团队 → 查看可用导游（按日期筛选无冲突导游）
    ↓
指派导游 → 设置导服费
    ↓
冲突检测（该导游当日是否已安排其他团）
    ↓
确认 → 导游收到通知
    ↓
导游出发前：导游借款申请 → 审批 → 放款
    ↓
带团中：导游录入实际费用（导游报账APP）
    ↓
回团后：导游报账 → 计调审核 → 财务审核
```

### 3.3 用车安排流程

```
查看待派车团队列表
    ↓
选择团队 → 设置接送时间/地点/人数
    ↓
选择车辆公司 → 选择车辆（按座位数筛选）
    ↓
冲突检测（该车辆当日是否已安排其他团）
    ↓
确认 → 车辆公司收到通知
    ↓
出团当日：司机执行接送
    ↓
回团后：车费对账
```

### 3.4 用房安排流程

```
查看待订房团队列表（按日期+城市）
    ↓
选择团队 → 汇总房型需求（标准间/单间/三人间/陪同房/加床房）
    ↓
选择酒店（按城市/星级/协议价筛选）
    ↓
设置入住日期/间数/房价
    ↓
发送预订请求 → 酒店确认
    ↓
营运中心：用房预订确认
    ↓
回团后：房费对账
```

### 3.5 地接安排流程

```
查看需要地接的团队
    ↓
选择团队 → 选择地接社（按目的地/协议筛选）
    ↓
设置地接内容（行程、人数、特殊需求）
    ↓
发送确认函 → 地接社确认
    ↓
地接社反馈（实际安排情况）
    ↓
回团后：地接对账
```

### 4.11 核心业务规则汇总

1. **资源冲突检测**：同一资源（导游/车辆/酒店房间）同一日期不可安排给多个团队；冲突时必须警告
2. **操作完整性**：所有 7 项资源安排完成后方可出团（可由系统参数配置是否强制）
3. **预订确认**：用房和门票预订需营运中心二次确认（PlanOrderHotelConfirm、PlanOrderScenicConfirm）
4. **二次结算**：与供应商的额外结算走二次结算流程（PlanOrder.ReturnList + 审核）
5. **成本录入时机**：资源安排时录入预算成本，回团后录入实际成本，差异自动标记
6. **导游借款上限**：借款金额 ≤ 团队预算成本 × 系统参数比例
7. **审核流程**：计调审核（PlanAuditListJD）→ 财务审核（PlanAuditList）→ 单团归档（PlanArchiveList）
8. **权限隔离**：计调只能操作本公司/部门的团队
