# TMS 产品路线图

> 基于 Odoo 19/20 + SaaS + 小程序的旅行社管理系统
> 日期：2026-09-12
> 对齐：技术架构思路.md（Odoo 19 → 20 演进路线）

---

## 路线图总览

```
2026 Q4 ─── Phase 1: 核心业务闭环 ──────────── 2027 Q1
                ↓
2027 Q1 ─── Phase 2: 财务深化 ──────────────── 2027 Q2
                ↓
2027 Q2 ─── Phase 3: 扩展功能 ──────────────── 2027 Q3
                ↓
2027 Q3 ─── Phase 4: 增强（小程序+BI+AI）────── 2027 Q4
                ↓
2027 Q4 ─── Phase 5: Odoo 20 升级 + Agentic AI  2028 Q1
```

## Phase 1：核心业务闭环

> **目标**：实现"线路→订单→计调→基础财务"最小闭环，可支撑单门店日常运营。

**预估时间**：2026 Q4 – 2027 Q1（3 个月）

### 功能列表

| 模块 | 功能项 | 对标易途菜单数 |
|------|--------|---------------|
| **tour_base** | 线路产品 CRUD、分类、行程明细（按天） | 线路模板、线路分类 |
| | 多价格体系（成人/儿童/老人/学生/婴儿） | 5 种价格字段 |
| | 发团计划（日期/余位/状态/同行价） | 团期计划 |
| | 线路上下架与审核 | 审核状态 |
| | 基础数据（分类/区域/结算方式/标签） | 基础数据 5 项 |
| **tour_order** | 团队订单（DT/DTO） | 团队订单 |
| | 散客订单（DSN/DSS/DSO） | 地接散拼、散客单组 |
| | 散客并团（含并团向导） | 散客并团 |
| | 订单状态流转与审核 | 订单审核 |
| | 单团变更 | 单团变更 |
| | 代订项目（门/房/签/票/餐/车/险） | 代订项目 |
| | 订单查询 | 订单查询 |
| **tour_operation** | 预订安排总览 | 预订安排 |
| | 导游安排 | 导游安排 |
| | 用车安排 | 用车安排 |
| | 用房安排 | 用房安排 |
| | 地接安排 | 地接安排 |
| **tour_resource** | 客户档案 | 客户档案 |
| | 供应商档案（12 类：地接社/酒店/景区/餐厅/车辆/票务/保险/签证/购物店/自费/平台商） | 资源中心 16 项 |
| | 导游档案 | 导游档案 |
| **tour_finance（基础）** | 单团收款/付款 | 单团收款/付款 |

### 里程碑

| 里程碑 | 时间 | 交付物 |
|--------|------|--------|
| M1.1 开发环境搭建 | 2026 W40 | Docker 化 Odoo 19 + PostgreSQL + Redis，tour_base 骨架 |
| M1.2 线路产品可用 | 2026 W44 | 线路 CRUD + 发团计划 + 审核，可录入完整线路产品 |
| M1.3 订单闭环 | 2026 W48 | 团队/散客订单 + 并团 + 代订，覆盖 7 种业务模式 |
| M1.4 计调可用 | 2027 W02 | 预订安排 + 派车派导 + 用房，计调可操作完整流程 |

### 依赖

- 开发环境：Docker + Odoo 19 CE + PostgreSQL 16 + Redis 7
- 数据：易途系统线路/供应商数据导出（用于迁移测试）
- 人员：后端开发 ×2、前端开发 ×1、产品经理 ×1

## Phase 5：Odoo 20 升级 + Agentic AI

> **目标**：升级到 Odoo 20，启用 Agentic AI 自主执行能力。

**预估时间**：2027 Q4 – 2028 Q1（3 个月）

### 功能列表

| 能力 | 场景 | AI 层级 |
|------|------|---------|
| 自动派车派导 | AI 决策 + 执行，冲突自动解决 | Layer 3 |
| 智能并团 | AI 匹配最优方案 + 自动合并 | Layer 3 |
| 自动对账 | AI 识别差异 + 发起调整 | Layer 3 |
| 财务预测 | 现金流/需求/采购预判 | Layer 3 |
| 智能 CRM | 自动评估线索概率、客户画像 | Layer 3 |
| 智能库存预测 | 票务库存、酒店房量预测 | Layer 3 |
| 营销自动化 | 老客户复购提醒、淡旺季推送 | Layer 3 |
| 智能客服 | AI 自主处理常见投诉、升级复杂问题 | Layer 3 |

### 里程碑

| 里程碑 | 时间 | 交付物 |
|--------|------|--------|
| M5.1 Odoo 20 Beta 测试 | 2027 W48 | 沙箱环境部署，模块兼容性测试 |
| M5.2 灰度升级 | 2028 W04 | 1-2 个小租户灰度升级 |
| M5.3 全量升级 | 2028 W08 | 所有租户升级到 Odoo 20 |
| M5.4 Agentic AI 启用 | 2028 W12 | 低风险 AI 功能先行（收款认领、行程生成） |
| **M5.5 AI 全面启用** | **2028 W16** | **高风险 AI 功能（派导、并团）** |

### 依赖

- Odoo 20 正式发布（预计 2026 年 10 月）
- Agentic AI 功能成熟度验证
- 所有自定义模块 Odoo 20 兼容性修复
- AI Agent 决策审计机制完善
