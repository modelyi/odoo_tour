# AGENTS.md

This file provides guidance to the AI agent when working with code in this repository.

## Project Structure

This is a phase-based project repository. Folders are prefixed with letters to enforce ordering:

| Folder | Phase | Contents |
|--------|-------|----------|
| `a-调研` | Research | Market research, requirements, feasibility studies |
| `b-蓝图` | Blueprint | Architecture designs, technical specs, plans |
| `c-系统实现` | Implementation | Source code, configs, build files |
| `d-交付验收` | Delivery & Acceptance | Test reports, acceptance criteria, release docs |

## Conventions

- Folder names use Chinese with a lowercase letter prefix and hyphen (e.g., `a-调研`). Preserve this naming exactly.
- Place artifacts in the phase they belong to. Do not create new top-level phase folders.
- All documentation and communication defaults to Chinese unless specified otherwise.
