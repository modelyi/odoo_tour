# TMS 旅行社管理系统

> 项目域名：tms.solepro.cloud | 技术栈：Odoo 19 + PostgreSQL 16 + Redis 7 + Docker + Nginx

从易途 V7（海螺旅行社在用系统）迁移到新一代旅行社管理平台，采用 SaaS 多租户架构，支持小程序（Uni-app），目标升级 Odoo 20（Agentic AI）。

## 项目结构

本项目采用阶段化管理，按顺序推进从调研到交付的完整流程。

```
tms/
├── INDEX.md         # 项目总目录（从这里开始）
├── AGENTS.md        # AI 协作规范
├── a-调研/          # 阶段一：调研 ✅
├── b-蓝图/          # 阶段二：蓝图设计 🔧
├── c-系统实现/      # 阶段三：系统实现 ⏳
└── d-交付验收/      # 阶段四：交付验收 ⏳
```

## 阶段工作流

### a-调研
明确项目目标与可行性。产出：需求分析、易途系统调研（247 菜单、27 表、18 万记录）、Odoo 功能映射。

### b-蓝图
基于调研成果进行系统设计。产出：PRD、产品路线图、业务规格（BS-01~08）、技术设计（架构/数据模型/模块划分）、财务合规基线。

### c-系统实现
按照蓝图进行编码开发。产出：Odoo 19 模块（14 个）、docker-compose、部署脚本。

### d-交付验收
验证系统是否满足需求。产出：测试报告、验收文档、发布说明。

## 命名规范

- 顶层文件夹以英文小写字母 + 连字符 + 中文名称命名（如 `a-调研`）
- 字母前缀用于确定阶段顺序，请勿修改
- 各阶段产出物放入对应文件夹，不要新建顶层文件夹

## 快速开始

```bash
cd c-系统实现/tms-platform
docker compose up -d
# 访问 https://tms.solepro.cloud
```
