# TMS 需求文档

> 旅行社业务与管理支持系统（Travel Management System）

## 1. 项目背景

旅行社日常业务涉及线路设计、客户咨询、订单处理、资源调度、财务结算等多个环节，目前依赖人工和分散工具管理，效率低且容易出错。需要一套统一系统来支撑核心业务流程，提升运营效率和管理水平。

## 2. 项目目标

- 统一管理旅行社核心业务流程（线路、订单、客户、财务）
- 减少人工重复操作，降低出错率
- 提供数据报表支持经营决策
- 支持多角色协作（销售、计调、财务、管理层）

## 3. 用户角色

| 角色 | 职责 |
|------|------|
| 管理员 | 系统配置、用户权限管理 |
| 销售 | 客户咨询、线路推荐、下单 |
| 计调 | 资源采购、行程安排、供应商对接 |
| 财务 | 收款确认、成本核算、结算管理 |
| 管理层 | 查看报表、审批、经营分析 |

## 4. 核心功能模块

### 4.1 线路管理

- 线路的创建、编辑、上下架
- 线路行程、价格、库存管理
- 支持多日期发团计划

### 4.2 客户管理

- 客户信息登记与分类（散客、团队、企业客户）
- 客户跟进记录
- 客户历史订单查询

### 4.3 订单管理

- 订单创建、修改、取消
- 订单状态流转（待确认 → 已确认 → 出行中 → 已完成 → 已取消）
- 订单关联线路、客户、费用明细

### 4.4 资源与供应商管理

- 供应商信息维护（酒店、车队、景区、地接社等）
- 资源采购与成本记录
- 供应商评价

### 4.5 财务管理

- 订单收款与退款
- 成本录入与利润核算
- 应收应付账款管理
- 财务报表（营收、利润、回款）

### 4.6 报表与统计

- 销售统计（按线路、时间段、销售人员）
- 财务报表（营收、成本、利润）
- 客户分析（新客/老客占比、复购率）

## 5. 非功能性需求

- 支持主流浏览器访问（Chrome、Firefox、Edge）
- 数据定期备份，支持恢复
- 操作日志可追溯
- 响应时间：常规操作 < 2 秒

## 6. 约束与假设

- 初期面向单门店使用，暂不考虑多门店/多分支机构场景
- 不涉及在线支付对接（首期），收款以线下确认为主
- 用户规模预估：10-30 人同时使用
