## 接口调用说明

### 登录
```
POST /Login/Login_Post
Content-Type: application/x-www-form-urlencoded

userAccount=demo_user&userPwd=<密码>&validateCode=
```

**已实测**：`validateCode` 传空字符串时服务端跳过验证码校验，直接返回 `{"flag":1,"error":""}`；传非空错误值才返回“验证码不正确”。
因此脚本无需 OCR 识别验证码，也无需浏览器自动化即可登录。

### 列表数据
```
POST /<Controller>/GetSearchList/<Resource.Key>   或   /<Controller>/SearchXxx/<Resource.Key>
Content-Type: application/x-www-form-urlencoded

page=1&pagesize=2000[&supTypeId=1][&itemType=57]
```

### 响应格式
```json
{ "Rows": [ { ... } ], "Total": 86925, "Sum": { ... } }
```

### 认证方式
- Cookie：`ASP.NET_SessionId`（先 GET `/` 建立会话，再 POST 登录）
- 登录接口：`POST /Login/Login_Post`
- 验证码接口：`GET /Login/GetValidateCode`（服务端未强制校验）

### 已知限制
- 单个列表接口 `pagesize` 上限实测 2000 条/页，需翻页取全量
- 部分模块（如平台商档案）当前账号无权限，返回“未经授权，您无权访问该页”
