## 1. 系统概述

易途旅行社管理系统是一套针对旅行社业务的 ERP 系统，以**产品研发 → 产品销售 → 计调操作 → 财务管理 → 决策分析**为核心主线，覆盖组团、地接、单项服务、接送等全业务类型。

**技术架构**：.NET MVC 5.2 / ASP.NET 4.8 / B/S 架构 / Vue.js + iView + Layui 前端
**产品矩阵**（7个子产品）：

| 产品 | 说明 |
|------|------|
| 旅行社管理系统（V7） | 核心 ERP，业务+财务+管理 |
| 掌上易途 APP | 移动端全功能（报名、查询、审批） |
| 同业分销系统 | 专线批发商 ↔ 零售商在线交易 |
| 导游报账 APP | 导游带团中录入费用、提交报账 |
| 小程序商城 | 面向 C 端的线路产品在线购买 |
| 车队管理系统 | 车辆调度、结算、绩效 |
| 百推 APP | 客服移动端快速录入报名单 |

## 3. 业务模式（从系统参数获取）

| 代号 | 模式 | 说明 |
|------|------|------|
| DT (1,2) | 团队输单 | 常规地接团队 |
| DSK (12) | 团期计划 | 先计划后报名，计划含同行价 |
| DSS (13) | 散客单组 | 独立散客组 |
| DSN (14,15) | 散客并团 | 散客拼团，先报后并 |
| 流转 (16) | 内部流转 | 集团内流转 |
| 产品计划 (17) | 发布线路协议再报名 | |
| 关键字并团 (18) | 关键字并团 | 行程以选择线路形式添加 |

## 5. 业务流程概览

```
产品研发（线路设计）
    ↓
产品销售（门市收客 / 同业分销 / 线上商城）
    ↓
订单确认（并团、审批）
    ↓
计调操作（预订资源、派车派导、成本控制）
    ↓
出团执行（接待、购物佣金记录）
    ↓
财务结算（收款、付款、对账、发票、佣金计算）
    ↓
决策分析（报表、利润分析）
```
