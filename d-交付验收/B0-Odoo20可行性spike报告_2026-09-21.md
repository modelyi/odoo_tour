## 关键发现（每条都有可复现命令，见 TDS-30 §3/§8）

1. **20 新增版本门禁**：模块 `version` 必须以 `20.1.` 开头且只能 2–5 段，否则
   `installable=False`，模块压根不出现在安装列表（`odoo/modules/module.py:500`）。
   → 36 个第三方模块的 manifest 是**第一道必改项**，AGENTS.md 的版本约定要更新。
2. **权限模型换了**：`ir.model.access` + `ir.rule` 两表在 20 **不存在**，统一为 `ir.access`
   （`operation∈crud` + `domain` + `kind`）。影响面：36 模块 ~390 处安全定义 +
   现网 516 行 access / 198 行 rule 的数据转换。**这是 B1 最大的单项工作量**，
   也是计划里原本没量出来的东西。
3. **`res.bank` 被删**，银行信息展平进 `res_partner_bank`（`acc_number→account_number`，
   `currency_id` 无对应）。自研 `tour.bank.account` 以 `res.bank` 为 comodel →
   registry 加载期 AssertionError，**连锁阻塞 19 个 tour_***。该列同时是 A0-2 的密文列。
4. **`hr.leave.type` 被删** → Webkul 7 个模块（payroll/loan/salary_advance 系）报
   `Model 'hr.leave.type' does not exist in registry`，**在假勤重构映射出来之前无法估工**。
5. **`odoo.service.db` 被删** → `tour_saas` 确认停用（与计划 §7 一致，非新增风险）。
6. 好消息：`web_responsive`、`hr_leave_request_aliasing`、`oh_employee_creation_from_user`
   **在 20 直接试装通过**；11 个「20 已删除的官方模块」里真正带数据的只有
   `hr_work_location` 3 行（`product_wishlist` 0 行、`hr_employee_location` 0 行）。
7. 数据语义风险 2 处（必须业务签字，不能机械搬）：
   `account_move.checked → review_state`、
   `account_move_line.deductible_amount`（金额）**→** `deductible_percentage`（百分比）。
