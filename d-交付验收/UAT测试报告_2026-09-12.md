## 四、阻塞问题

### 🔴 关键阻塞: tour_base 模块未安装

**现象**: 数据库 `tms` 中 `ir_module_module.tour_base.state = 'uninstalled'`，所有业务模型、表、视图均不存在。

**影响**: 系统仅有 Odoo 原生登录页，无任何旅行社业务功能。

**可能原因**:
1. 模块部署到容器 (`/mnt/extra-addons/tour_base`) 后未执行安装命令
2. 容器刚重启 (health: starting)，可能还在初始化中
3. 安装过程中遇到错误导致回滚

**修复建议**:
```bash
# 方法 1: 通过命令行安装
docker exec tms-odoo odoo -d tms -i tour_base --stop-after-init

# 方法 2: 通过 UI 安装
# 登录 → Apps → 搜索 "TMS Base" → Install
```

## 五、改进建议

### 高优先级 (阻塞验收)

1. **安装 tour_base 模块** — 当前系统无业务功能，安装后才能继续验收
2. **添加种子数据** — 模块缺少 `data/` 目录下的初始分类数据（如"国内游"、"出境游"等默认分类）
3. **添加 demo 数据** — 用于测试和演示的示例线路数据

### 中优先级

4. **完善发团计划模型** — `tour.departure.plan` 在 manifest 中声明但代码中未实现
5. **添加单元测试** — 当前模块无测试文件
6. **Redis session 启用** — 配置中 `session_redis_url` 被注释，多 worker 场景需要共享 session
7. **关闭 dev_mode** — 生产环境应关闭 `dev_mode = reload,qweb`
8. **配置中文语言** — 当前用户语言为 `en_US`，应默认安装并设置 `zh_CN`

### 低优先级

9. **添加 tour_line_type 的 tree 视图** — 当前只有 tree,form，缺少 tree hierarchy 展示
10. **添加 data migration 脚本** — 从易途系统迁移 212 条线路数据
11. **添加报表模板** — 行程单打印、出团通知等 PDF 模板
12. **移动端适配测试** — 验证 Odoo 19 的响应式布局在移动端表现
