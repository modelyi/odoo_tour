# 批5 候选清单与优先级建议

- 日期：2026-10-07
- 性质：**供用户圈定范围的候选清单**，未实施任何内容
- 来源：批3.5 仿真报告遗留项、批4 验收报告已知偏差（6 项）、BS-08 验收标准缺口核对、蓝图未落地规格
- 排序原则：财务正确性（P0，上线前必须）> 产品功能完整性（P1，功能不丢失）> 蓝图大项（P2，需单独圈定）

## 一、P0 财务正确性（佣金账务闭环，上线前必须）

| # | 项目 | 出处 | 领域 | 说明 |
|---|---|---|---|---|
| P0-1 | 佣金会计分录落地 | BS-08 §4.10 | 财务 | 佣金确认/分成/代扣个税生成凭证：经营收入（佣金总额）、劳务成本（导游分成）、应交个税。当前佣金单只做台账，不进总账，与"全库借贷平衡"体系脱节 |
| P0-2 | 增值税销项税额自动计算 | BS-08 AC-19 | 财务 | 佣金收入确认时按差额征税口径算销项税（涉 BS-11 参数） |
| P0-3 | 单团损益 `profit_no_shop` 口径 | BS-08 AC-16 | 财务 | 损益视图区分含购物/不含购物两种口径；已交付的 ta_team_pnl 文件需扩展，单独排期 |
| P0-4 | 退单红字发票与个税抵扣账务 | BS-08 §4.2 | 财务 | 当前为"拦截已结算佣金+简化退单"；完整口径需独立退单单据、红字发票、已代扣个税抵扣（依赖 BS-12 发票体系，可拆分：先做单据+个税抵扣，红字发票随 BS-12） |
| P0-5 | 期初建账（补期初余额+总账三表仿真） | BS-16 | 财务 | 上线前必须；live DB 各科目余额清单已实测在案 |
| P0-6 | 收入成本确认口径修正（O2C/P2P 过账纠偏） | BS-14 | 财务 | 已过账凭证的科目口径纠偏，涉数据变更，需单独方案+备份门禁 |

## 二、P1 产品功能完整性（统计报表 + 引擎扩展）

| # | 项目 | 出处 | 领域 | 说明 |
|---|---|---|---|---|
| P1-1 | **购物统计报表包**（核心，用户已点名） | BS-08 AC-10/13/14/15 + 报表清单 9 项 | 财务+导游 | 购物对账（应付/已付佣金）、导游业绩统计（人均购物、税前/税后分成）、多维度统计（年龄/性别/线路/客源地）、个税月度汇总申报导出。当前 ta.shop 仅 list,form 视图，无 pivot/graph/报表动作 |
| P1-2 | 司机/陪同分成引擎扩展 | BS-08 §3.2/§4.6 | 导游 | 协议模型已含 staff_type（司机/陪同），引擎目前仅接入导游；需多层分成（导游+司机+陪同共享佣金池）+ 各自个税代扣 |
| P1-3 | 人均线/算法参数配置化 | BS-08 §4.7/§4.8 | 导游 | 导游人均线（菜单 3852）、人均算法设置（菜单 3853）——现为硬编码于协议阶梯规则，无全局配置界面 |
| P1-4 | 购物成本录入 | BS-08 §4.4 | 财务+计调 | 购物成本模型（菜单 4305）缺失，影响购物毛利口径 |
| P1-5 | 佣金批量收款 | BS-08 AC-17 | 财务 | 多笔佣金同时收款（当前逐笔） |
| P1-6 | 导游绩效 expense_count 跨月口径 | 批3.5 §5.5 | 财务+导游 | 报账月 ≠ 带团月时绩效行报账次数为 0 但成本已计入；需产品裁定归属口径 |
| P1-7 | 供应商账单日期=发团日问题 | 批3.5 §5.6 | 财务 | 未来日期账单在会计期间筛选出现"未来凭证"观感；建议账单日取操作当日 |
| P1-8 | 订单报名名单行内下拉 UI 复核 | 批3.5 §5.7 | 计调 | 儿童单价联动回填不稳定，需人工 UI 复核（低成本） |
| P1-9 | 大表视图物化（OBS-01 延续） | 批3.5 §6 | 财务+性能 | 8 万+ 成本条目后账龄/损益/付款视图性能；与 P1-1 统计报表同批做（新报表直接走物化设计） |
| P1-10 | 演示数据注入方案 | 批4 报告偏差 #6 | 全领域 | 购物三模型上线演示数据（仿真样例已留），或明确"客户自建" |

## 四、建议批次划分（供圈定）

- **批5（建议默认范围）= P0-1/2/3 + P1-1/2/3/9**：一次交付"佣金账务闭环 + 购物统计报表 + 司机陪同分成 + 性能物化"，导游/财务两条线同时收口。
- **批6 = P0-4/5/6 + P1-4/5/6/7/8**：上线前财务收尾（期初建账、口径纠偏、红字单据）+ 低成本口径修正。
- **批7+ = P2 蓝图大项**：按商业优先级单独立项（差额征税、发票、线上销售等）。

## 五、明确不做（口径备忘）

- 旧库 5 条购物佣金规则数据**不迁移**（仅调研参考，用户已裁定）；
- 导游 APP 端录入（AC-01）暂以"系统补录（source=sys）"承载，APP 通道随线上化立项。
