## 一、6 场景逐一结论

### 场景 A：接单 → 收款（核心闭环）✅ 通过
证据（odoo shell 实测，均 PASS）：
- `tour.plan.action_confirm()` 草稿→待确认→已确认，自动创建 1:1 分析账户 `account.analytic.account`（命名「团号-团名」）与单团核算台账 `tour.plan.account`；重复确认不重复建（幂等）。
- 收款认领 `tour.payment.claim`：编号自动 `SK-000012`；认领 `action_claim`（0→1）；审核 `action_audit`（1→2）生成 `account.move`（已过账）：
  - 借 **1002 银行存款 106000** / 贷 **2203.01 预收团款 106000**，借贷平衡；
  - 两行均挂单团分析账户 `{'<analytic_id>': 100.0}`；
  - `compliance_ref = cas14_advance` ✅。
- 备注：`action_audit` 二次调用会抛 `ValidationError`（状态守卫），但凭证生成有 `move_id` 幂等守卫，**不会重复生成凭证**——凭证幂等满足。

### 场景 B：佣金个税（分佣）✅ 通过
- 劳务报酬累进个税（BS-08 §11）实测正确：**3000→440**、**10000→1600**、800→0（不预扣）。
- 佣金 `tour.commission`（编号 `YJ-000008`）：确认生成计提凭证（过账）：
  - 借 **6401.07 导服成本 10000** / 贷 **2241.02 应付导游 8400** / 贷 **2221.05 应交个税 1600**，借贷平衡；
  - 个税=1600、实发=8400、留存=2000 均正确。
- 发放 `action_pay`：借 **2241.02 8400** / 贷 **1002 银行存款 8400**，借贷平衡；幂等（不重复生成）。
- 备注：计提凭证中 2221.05 个税行未挂分析账户（成本/应付款行已挂）；发放凭证两行均未挂分析账户——不影响单团成本归集，属一致性小瑕疵。

### 场景 C：收入确认 + 差额征税 + 单团核算 ⚠️ 通过（含 1 缺陷）
- 收入确认 `action_recognize_revenue`（总额法 6%）：借 **2203.01 106000** / 贷 **6001.01 收入(不含税) 100000** / 贷 **2221.01 销项 6000**，借贷平衡；`compliance_ref=cas14_principal`；幂等。
- 差额征税 `action_generate_vat_deduction`：借 **2221.03 3600** / 贷 **6401.01 3600**（63600 可扣除成本 ÷1.06×6%），借贷平衡；`compliance_ref=vat_diff`；幂等。
- 单团核算 `tour.plan.account`（从 analytic 派生）：收入=100000、成本=70000（地接 60000 + 导服 10000）、利润=30000、预收余额=0（已结转）——**均正确**。
- 🔴 **缺陷 P1（差额征税申报口径）**：生成抵减凭证后，台账申报字段被重复计算——
  - `vat_deduct_amount` 实测 **3803.77**（理想 **3600**），因 `cost_deductible` 被算成 **67200**（理想 **63600**）：抵减贷方行「贷 6401.01 3600」被 `_plan_cost_vat_split` 的 `abs()` 再次计入可扣除成本；
  - 连带 `vat_payable`（净应纳）实测 **2196.23**（理想 **2400**）。
  - 凭证本身正确（3600），但申报口径 `vat_deductible_total / vat_deduct_amount / vat_payable` 在抵减后失真，影响增值税申报附列资料三。

## 六、发现的问题

1. 🔴 **P1：差额征税申报口径重复计算**（`tour_accounting/models/accounting_mixin.py::_plan_cost_vat_split` 用 `abs()` 汇总可扣除成本，抵减凭证贷方行「贷 6401.0N」被再次计入）。导致 `tour.plan.account` 的 `vat_deductible_total / vat_deduct_amount / vat_payable` 在生成抵减凭证后失真（抵减额 3600→3803.77，净应纳 2400→2196.23），影响增值税申报。抵减凭证本身金额正确，仅申报口径字段有偏。
   - 建议：`_plan_cost_vat_split` 改为只汇总借方（`amount < 0`）或净额，或抵减凭证贷方行不挂 analytic。
2. 🟡 轻微：`tour.payment.claim.action_audit` 重复调用抛错（状态守卫），但凭证不重复生成——建议与其他 action 一致改为静默 no-op 或 UI 隐藏按钮。
3. 🟡 轻微：佣金计提/发放凭证的个税行与发放行未挂单团分析账户（不影响成本/收入归集，但与其他凭证的 analytic 挂载口径不一致）。
