# CFO 门户功能说明

## 概述

CFO 门户是专为首席财务官设计的财务管理界面，提供财务审批、监控和报表功能。

## 访问方式

**访问地址**
```
http://tms.solepro.cloud/my/cfo
```

**登录账号**
- 需要具有 CFO 门户用户角色的账号
- 默认 admin 账号已分配 CFO 角色

## 功能模块

### 1. 财务概览仪表盘

**统计卡片**
- 待审批报账：显示待审批报账数量和总金额
- 待审批佣金：显示待审批佣金数量和总金额
- 待审批借款：显示待审批借款数量和总金额

**最近待审批项目**
- 最近 5 条待审批报账
- 最近 5 条待审批佣金
- 最近 5 条待审批借款

### 2. 报账审批管理

**功能**
- 查看所有待审批报账单
- 查看报账详情和附件
- 审批通过报账单
- 按日期、金额、状态排序

**审批流程**
1. 进入"报账审批"菜单
2. 查看待审批报账列表
3. 点击"审批"按钮查看详情
4. 查看报账信息、附件
5. 点击"审批通过"完成审批

### 3. 佣金审批管理

**功能**
- 查看所有待审批佣金
- 查看佣金计算详情
- 按导游、团队筛选

**审批状态**
- 已计算 (calculated)：待审批
- 已审批 (approved)：审批通过
- 已支付 (paid)：已支付

### 4. 借款审批管理

**功能**
- 查看所有待审批借款
- 查看借款金额和余额
- 按申请日期排序

**审批状态**
- 已申请 (requested)：待审批
- 已发放 (disbursed)：已发放
- 已结清 (settled)：已结清

## 权限控制

### 数据访问范围

CFO 角色可以访问：
- 所有报账单（不限导游）
- 所有佣金记录
- 所有借款记录
- 所有导游档案
- 所有团队信息
- 所有报账附件

### 操作权限

| 操作 | 报账 | 佣金 | 借款 |
|------|------|------|------|
| 查看 | ✓ | ✓ | ✓ |
| 审批 | ✓ | - | - |
| 修改 | ✓ | ✓ | ✓ |
| 删除 | ✗ | ✗ | ✗ |

## 角色分配

### 通过数据库分配

```sql
-- 查找 CFO 用户组
SELECT id, name FROM res_groups WHERE name = 'CFO 门户用户';

-- 给用户分配 CFO 角色
INSERT INTO res_groups_users_rel (gid, uid)
VALUES (cfo_group_id, user_id);
```

### 通过 Odoo 后台分配

1. 登录 Odoo 后台
2. 进入"设置" → "用户"
3. 选择用户
4. 在"权限"标签页勾选"CFO 门户用户"

## 技术实现

### 模块结构

```
tour_cfo_portal/
├── __manifest__.py          # 模块配置
├── __init__.py
├── controllers/
│   ├── __init__.py
│   └── portal.py            # CFO 门户控制器
├── models/
│   ├── __init__.py
│   └── res_users.py         # 用户扩展
├── views/
│   ├── portal_templates.xml # 布局模板
│   └── portal_pages.xml     # 页面模板
└── security/
    ├── groups.xml           # 用户组定义
    ├── ir.model.access.csv  # 模型访问权限
    └── ir_rule.xml          # 记录规则
```

### 关键路由

| 路由 | 功能 |
|------|------|
| `/my/cfo` | CFO 门户首页 |
| `/my/cfo/expenses` | 报账审批列表 |
| `/my/cfo/expenses/<id>` | 报账审批详情 |
| `/my/cfo/expenses/<id>/approve` | 审批报账 |
| `/my/cfo/commissions` | 佣金审批列表 |
| `/my/cfo/loans` | 借款审批列表 |

### 安全规则

- CFO 可以查看所有财务数据（domain: `[(1, '=', 1)]`）
- 只能审批，不能删除
- 附件访问控制：只能访问报账相关附件

## 使用场景

### 场景 1：日常审批

1. 登录 CFO 门户
2. 查看财务概览，了解待审批数量
3. 进入相应审批页面
4. 逐项审批

### 场景 2：财务监控

1. 查看财务概览仪表盘
2. 关注待审批金额
3. 查看最近待审批项目
4. 及时处理异常

### 场景 3：附件审核

1. 进入报账审批详情
2. 查看附件列表
3. 下载附件审核
4. 完成审批

## 故障排查

### 问题 1：无法访问 CFO 门户

**症状**：访问 `/my/cfo` 提示无权限

**解决**：
1. 检查用户是否有 CFO 角色
2. 检查模块是否已安装
3. 重启 Odoo 服务

### 问题 2：看不到待审批数据

**症状**：列表为空但有数据

**解决**：
1. 检查数据状态是否符合审批条件
2. 检查记录规则是否正确
3. 清除缓存后重试

### 问题 3：审批按钮不显示

**症状**：详情页没有审批按钮

**解决**：
1. 检查报账状态是否为待审批
2. 检查用户权限
3. 检查视图模板
