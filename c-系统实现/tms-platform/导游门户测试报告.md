## 测试步骤

### 步骤 1: 为导游创建门户用户
1. 登录 Odoo 后台: http://localhost:8070/web/login
2. 进入 **导游管理 → 导游档案**
3. 选择一个导游（需要有 partner_id）
4. 点击 **"发送门户邀请"** 按钮
5. 系统会自动创建 portal 用户并发送邮件

### 步骤 2: 测试门户登录
1. 使用门户用户账号登录: http://localhost:8070/web/login
2. 登录后访问: http://localhost:8070/my/guide
3. 应该看到门户首页，包含：
   - 我的派团数量
   - 佣金记录数量
   - 借款单数量
   - 报账单数量
   - 最近派团和佣金列表

### 步骤 3: 测试各功能页面
1. **派团查看**: 点击"我的派团"，查看派团列表和详情
2. **佣金查询**: 点击"佣金查询"，查看佣金明细（含税前分成、个税、实发）
3. **借款状态**: 点击"借款状态"，查看借款单和冲抵情况
4. **报账提交**: 点击"我的报账" → "新建报账"，填写表单并提交

### 步骤 4: 验证数据隔离
1. 使用不同的门户用户登录
2. 确认每个导游只能看到自己的数据
3. 确认无法访问其他导游的派团、佣金、借款、报账

## 技术细节

### 依赖模块
- portal (Odoo 核心)
- website (Odoo 核心)
- tour_resource (自定义)
- tour_accounting (自定义)
- tour_order (自定义)
- hr_expense (Odoo 核心)

### 数据隔离规则
```xml
<!-- 导游只能看自己的佣金 -->
[('guide_id.partner_id', '=', user.partner_id.id)]

<!-- 导游只能看自己的借款 -->
['|',
    ('guide_id.partner_id', '=', user.partner_id.id),
    ('employee_id.user_id.partner_id', '=', user.partner_id.id)]

<!-- 导游只能看自己的派团 -->
[('resource_type', '=', 'guide'),
 ('guide_id.partner_id', '=', user.partner_id.id)]
```

### 门户用户创建逻辑
```python
# 通过 partner_id 查找或创建 portal 用户
user = Users.search([
    ('partner_id', '=', guide.partner_id.id),
    ('share', '=', True),  # portal 用户标记
], limit=1)

if not user:
    user = Users.create({
        'name': guide.name,
        'login': guide.partner_id.email or guide.guide_code,
        'partner_id': guide.partner_id.id,
        'share': True,
        'groups_id': [(6, 0, [portal_group_id])],
    })
```
