## 手动测试步骤

### 步骤 1: 准备测试数据
1. 登录 Odoo 后台: http://localhost:8070/web/login
   - 用户名: admin
   - 密码: admin

2. 进入 **导游管理 → 导游档案**

3. 选择一个导游，确保：
   - 已关联联系人 (partner_id)
   - 联系人有邮箱地址

### 步骤 2: 发送门户邀请
1. 在导游表单中，点击 **"发送门户邀请"** 按钮
2. 系统会自动：
   - 创建 portal 类型的 res.users
   - 发送邀请邮件到导游邮箱
   - 设置 portal_user_id 关联

### 步骤 3: 门户用户登录
1. 访问: http://localhost:8070/web/login
2. 使用门户用户账号登录（邮箱/密码）
3. 登录后访问: http://localhost:8070/my/guide

### 步骤 4: 测试门户功能

#### 4.1 首页仪表盘
- 查看 4 个统计卡片（派团、佣金、借款、报账）
- 查看最近派团和佣金列表

#### 4.2 派团查看
- 点击"我的派团"
- 查看派团列表
- 点击某条记录查看详情

#### 4.3 佣金查询
- 点击"佣金查询"
- 查看佣金列表（含筛选器）
- 点击查看详情（税前分成、个税、实发）

#### 4.4 借款状态
- 点击"借款状态"
- 查看借款单列表
- 查看冲抵情况和报账截止日
- 超期借款会显示红色标记

#### 4.5 报账提交
- 点击"我的报账"
- 点击"新建报账"
- 填写表单：
  - 报账说明
  - 关联团队（可选）
  - 费用类别
  - 金额
  - 发票号
  - 关联借款（冲抵，可选）
- 提交后查看报账详情

## 技术细节

### 数据隔离规则
```python
# 佣金
[('guide_id.partner_id', '=', user.partner_id.id)]

# 借款
['|',
    ('guide_id.partner_id', '=', user.partner_id.id),
    ('employee_id.user_id.partner_id', '=', user.partner_id.id)]

# 派团
[('resource_type', '=', 'guide'),
 ('guide_id.partner_id', '=', user.partner_id.id)]

# 报账
['|',
    ('x_guide_id.partner_id', '=', user.partner_id.id),
    ('employee_id.user_id.partner_id', '=', user.partner_id.id)]
```

### 门户用户创建逻辑
```python
# 查找或创建 portal 用户
user = Users.search([
    ('partner_id', '=', guide.partner_id.id),
    ('share', '=', True),
], limit=1)

if not user:
    user = Users.create({
        'name': guide.name,
        'login': guide.partner_id.email,
        'partner_id': guide.partner_id.id,
        'share': True,
        'groups_id': [(6, 0, [portal_group_id])],
    })
```
