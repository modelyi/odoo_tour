## 重构概述

### 原实现（已废弃）

**问题**:
- ❌ 按账户类型汇总余额，非实际现金流动分析
- ❌ 无法区分现金流入/流出
- ❌ 无法正确分类经营/投资/筹资活动
- ❌ 与利润表/资产负债表重复，无独立价值

**代码示例**:
```python
_CASH_FLOW_TYPE_MAP = {
    'cash_in_from_operation0': ['asset_cash', 'asset_current'],
    'cash_out_operation1': ['liability_current', 'expense'],
}
```

### 新实现（直接法）

**核心改进**:
- ✅ 基于会计分录分析实际现金流动
- ✅ 按对方科目自动分类（经营/投资/筹资）
- ✅ 区分现金流入/流出方向
- ✅ 支持明细下钻到会计凭证
- ✅ 符合《企业会计准则第 31 号——现金流量表》

## 技术方案

### 1. 核心逻辑

**文件**: `report/cash_flow_report.py`

**关键方法**:

```python
def _compute_cash_flow(self, date_from, date_to):
    """
    计算期间内的现金流量
    
    1. 获取所有现金账户（asset_cash, asset_current）
    2. 查询期间内所有涉及现金的分录行
    3. 按对方科目分类每笔现金流动
    4. 汇总经营/投资/筹资活动的流入/流出
    """
```

```python
def _classify_cash_flow(self, cash_line, counterpart_line):
    """
    根据对方科目分类现金流量
    
    分类规则：
    - 现金 ↔ 收入/成本/费用 = 经营活动
    - 现金 ↔ 应收/应付 = 经营活动（营运资金变动）
    - 现金 ↔ 固定资产 = 投资活动
    - 现金 ↔ 股权/长期负债 = 筹资活动
    """
```

### 2. 分类规则矩阵

| 现金方向 | 对方科目类型 | 分类 | 示例 |
|---------|------------|------|------|
| 流入 | income, income_other | 经营 | 客户付款、收到服务款 |
| 流出 | expense, expense_direct_cost | 经营 | 支付地接费、酒店成本 |
| 流入 | asset_receivable (减少) | 经营 | 应收账款收回 |
| 流出 | liability_payable (减少) | 经营 | 支付供应商款项 |
| 流出 | asset_fixed, asset_non_current | 投资 | 购买车辆、设备 |
| 流入 | asset_fixed, asset_non_current | 投资 | 处置固定资产 |
| 流入 | equity | 筹资 | 股东投资 |
| 流出 | equity | 筹资 | 分配股利 |
| 流入 | liability_non_current | 筹资 | 取得长期借款 |
| 流出 | liability_non_current | 筹资 | 偿还长期借款 |

## 勾稽关系验证

### 资产负债表 ↔ 现金流量表

```
资产负债表：
  货币资金（期末） - 货币资金（期初） = 现金净增加额

现金流量表：
  经营净现金流 + 投资净现金流 + 筹资净现金流 = 现金净增加额

验证：
  两者必须相等
```

### 利润表 ↔ 现金流量表

```
利润表：
  净利润

现金流量表（间接法，未实现）：
  净利润
  + 折旧摊销
  ± 营运资金变动
  = 经营活动净现金流
```

## 性能优化

### 大数据量处理

**问题**: 期间内可能有数万笔分录

**优化方案**:
1. 按期间分批计算
2. 使用 SQL 聚合减少 Python 循环
3. 缓存计算结果
4. 异步计算（后台任务）

### 当前实现

```python
move_lines = self.env['account.move.line'].search([
    ('account_id', 'in', cash_accounts.ids),
    ('date', '>=', date_from),
    ('date', '<=', date_to),
    ('parent_state', '=', 'posted'),
])
```

**优化建议**（后续迭代）:
```python
# 使用 SQL 直接聚合
query = """
    SELECT 
        CASE 
            WHEN counterpart.account_type IN ('income', 'income_other') THEN 'operating_in'
            WHEN counterpart.account_type IN ('expense', 'expense_direct_cost') THEN 'operating_out'
            -- ...
        END as category,
        SUM(cash_line.debit - cash_line.credit) as amount
    FROM account_move_line cash_line
    JOIN account_move_line counterpart 
        ON cash_line.move_id = counterpart.move_id
        AND counterpart.account_id != cash_line.account_id
    WHERE cash_line.account_id IN %s
        AND cash_line.date BETWEEN %s AND %s
    GROUP BY category
"""
```

## 已知限制

### 1. 多借多贷分录

**问题**: 一笔分录有多个现金账户和多个对方科目

**当前处理**: 按对方科目逐行分类

**改进方案**: 按金额比例分配或要求用户规范制单

### 2. 现金内部转账

**问题**: 银行存款 ↔ 库存现金

**当前处理**: 分类为"未分类"，不计入现金流量

**改进方案**: 识别并排除现金内部转账

### 3. 汇率影响

**问题**: 外币现金账户的汇率变动

**当前处理**: 未处理
