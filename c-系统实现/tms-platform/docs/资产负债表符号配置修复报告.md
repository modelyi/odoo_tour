# 资产负债表符号配置修复报告

**日期**: 2026-09-17  
**模块**: tour_accounting (v19.0.4.6.0)  
**优先级**: P1  
**状态**: ✅ 已完成

---

## 问题描述

资产负债表中，负债和所有者权益显示符号错误：
- ❌ 负债显示为负数（应为正数）
- ❌ 所有者权益显示为负数（应为正数）
- ❌ 资产负债表不平衡（资产 ≠ 负债 + 所有者权益）

---

## 根本原因

`account_financial_report` 表中，负债和所有者权益节点的 `sign` 配置错误：

**修改前**:
```sql
-- 所有节点 sign = 1
资产负债表 (id=8, sign=1)
├── 资产 (id=9, sign=1) ← 正确
├── 负债 (id=10, sign=1) ← 错误，应为 -1
│   └── 负债 (id=11, sign=1) ← 错误，应为 -1
└── Owner's Equity (id=45, sign=1) ← 错误，应为 -1
    ├── Equity (id=46, sign=1) ← 错误，应为 -1
    └── 报告利润 (id=12, sign=1) ← 错误，应为 -1
```

**会计原理**:
- 资产类账户：借方余额（debit > credit）
- 负债类账户：贷方余额（credit > debit）
- 所有者权益类账户：贷方余额（credit > debit）

**Odoo 报表符号规则**:
- `sign = 1`：使用自然余额（debit - credit）
- `sign = -1`：反转余额（credit - debit）

---

## 修复方案

### SQL 修复

```sql
-- 负债类：sign = -1
UPDATE account_financial_report 
SET sign = '-1'
WHERE id IN (10, 11);

-- 所有者权益类：sign = -1
UPDATE account_financial_report 
SET sign = '-1'
WHERE id IN (45, 46, 12);
```

### 修复后结构

```
资产负债表 (id=8, sign=1)
├── 资产 (id=9, sign=1) ← 借方余额显示为正
├── 负债 (id=10, sign=-1) ← 贷方余额反转为正
│   └── 负债 (id=11, sign=-1) ← 贷方余额反转为正
└── Owner's Equity (id=45, sign=-1) ← 贷方余额反转为正
    ├── Equity (id=46, sign=-1) ← 贷方余额反转为正
    └── 报告利润 (id=12, sign=-1) ← 贷方余额反转为正
```

## 三表符号一致性

### 利润表（P&L）

| 项目 | 账户类型 | 自然余额 | sign | 显示符号 |
|------|---------|---------|------|---------|
| 收入 | income | 贷方 | -1 | 正数 ✓ |
| 其他收入 | income_other | 贷方 | 1 | 正数 ✓ |
| 营业成本 | expense_direct_cost | 借方 | 1 | 正数 ✓ |
| 费用 | expense | 借方 | -1 | 负数 ✓ |

**净利润** = 收入 - 营业成本 - 费用

### 资产负债表（BS）

| 项目 | 账户类型 | 自然余额 | sign | 显示符号 |
|------|---------|---------|------|---------|
| 资产 | asset_* | 借方 | 1 | 正数 ✓ |
| 负债 | liability_* | 贷方 | -1 | 正数 ✓ |
| 所有者权益 | equity | 贷方 | -1 | 正数 ✓ |

**会计等式**: 资产 = 负债 + 所有者权益

### 勾稽关系

```
利润表：
  净利润 = 收入 - 成本 - 费用

资产负债表：
  未分配利润（期末） = 未分配利润（期初） + 净利润
  
  资产 = 负债 + 所有者权益
       = 负债 + (实收资本 + 资本公积 + 盈余公积 + 未分配利润)
```

## 现金流量表符号

### 直接法

| 类别 | 方向 | 显示符号 | 说明 |
|------|------|---------|------|
| 经营活动 - 流入 | in | 正数 | 客户付款、收到服务款 |
| 经营活动 - 流出 | out | 负数 | 支付供应商、支付成本 |
| 投资活动 - 流入 | in | 正数 | 处置固定资产 |
| 投资活动 - 流出 | out | 负数 | 购买固定资产 |
| 筹资活动 - 流入 | in | 正数 | 吸收投资、取得借款 |
| 筹资活动 - 流出 | out | 负数 | 偿还借款、分配股利 |

**现金净增加额** = 经营净现金流 + 投资净现金流 + 筹资净现金流

### 勾稽关系

```
现金流量表：
  期末现金 = 期初现金 + 现金净增加额

资产负债表：
  货币资金（期末） = 现金流量表：期末现金

验证：两者必须相等
```
