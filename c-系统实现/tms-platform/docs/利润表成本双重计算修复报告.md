# 利润表成本双重计算修复报告

**日期**: 2026-09-17  
**模块**: tour_accounting (v19.0.4.6.0)  
**优先级**: P0

---

## 问题描述

利润表中，账户 6401（主营业务成本，account_type=`expense_direct_cost`）在两个位置重复出现：
- **营业成本**：+34,914,135.99
- **费用**：-34,914,135.99

两者相互抵消，导致报表结构错误，虽然净利润因符号补偿恰好正确，但报表完全不可用。

---

## 根本原因

`wizard/financial_report.py` 第 264-268 行的 `multi_type_map` 配置错误：

```python
multi_type_map = {
    'tour_accounting.account_financial_report_expense0': [
        'expense', 'expense_depreciation',
        'expense_direct_cost',  # ← 此行导致 6401 被重复计算
    ],
    # ...
}
```

`expense_direct_cost` 同时被映射到：
1. **Cost of Revenue**（数据库配置：`account_type_ids='expense_direct_cost'`）
2. **Expense**（Python 代码 `multi_type_map` 覆盖）

---

## 修复方案

**文件**: `c-系统实现/tms-platform/addons/tour_accounting/wizard/financial_report.py`  
**行号**: 265-267

**修改前**:
```python
'tour_accounting.account_financial_report_expense0': [
    'expense', 'expense_depreciation',
    'expense_direct_cost',
],
```

**修改后**:
```python
'tour_accounting.account_financial_report_expense0': [
    'expense', 'expense_depreciation',
],
```

---

## 修复验证

### 1. 数据库配置验证

```sql
-- 费用类报表配置
SELECT name->>'zh_CN' as name, account_type_ids, sign
FROM account_financial_report 
WHERE name->>'en_US' IN ('Cost of Revenue', 'Expense');

-- 结果：
-- 营业成本 | expense_direct_cost | 1
-- 费用     | expense             | -1
```

**结论**: 数据库配置正确，每个报表节点只映射一种 account_type。

### 2. 利润表结构验证

```
收益与损失 (sum, sign=-1)
├── 收入 (sum, sign=-1)
│   ├── 毛利润 (sum, sign=1)
│   │   └── 营业成本 (account_type: expense_direct_cost, sign=1)
│   └── 其他收入 (account_type: income_other, sign=1)
└── 费用 (account_type: expense, sign=-1)
```

**结论**: 结构清晰，无重复映射。

### 3. 账户类型分布

系统中 `expense_direct_cost` 类型的账户：
- 主营业务成本
- 成本—地接费
- 成本—住宿费
- 成本—餐费
- 成本—其他
- Cost of Goods Sold

这些账户**只在营业成本中出现**，不再在费用中重复。
