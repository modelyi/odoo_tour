## 重构方案

### 核心思路：直接法

基于会计分录分析现金流动，按对方科目分类：

```
现金 ↔ 应收账款/应付账款 = 经营活动
现金 ↔ 收入/成本/费用   = 经营活动
现金 ↔ 固定资产         = 投资活动
现金 ↔ 股权/长期负债    = 筹资活动
```

### 实现逻辑

```python
def _compute_cash_flow(self, date_from, date_to):
    """
    分析期间内所有涉及现金账户的会计分录
    """
    # 1. 获取所有现金账户
    cash_accounts = self.env['account.account'].search([
        ('account_type', 'in', ['asset_cash', 'asset_current'])
    ])
    
    # 2. 查询期间内所有涉及现金的分录行
    move_lines = self.env['account.move.line'].search([
        ('account_id', 'in', cash_accounts.ids),
        ('date', '>=', date_from),
        ('date', '<=', date_to),
        ('parent_state', '=', 'posted')
    ])
    
    # 3. 按对方科目分类
    operating_cash_flow = 0
    investing_cash_flow = 0
    financing_cash_flow = 0
    
    for line in move_lines:
        # 找到同一分录中的对方科目
        counterpart_lines = line.move_id.line_ids - line
        
        for counterpart in counterpart_lines:
            cash_amount = line.debit - line.credit  # 正数=流入，负数=流出
            
            # 按对方科目类型分类
            if counterpart.account_id.account_type in ['asset_receivable', 'liability_payable']:
                operating_cash_flow += cash_amount
            elif counterpart.account_id.account_type in ['income', 'income_other', 'expense', 'expense_direct_cost']:
                operating_cash_flow += cash_amount
            elif counterpart.account_id.account_type in ['asset_fixed', 'asset_non_current']:
                investing_cash_flow += cash_amount
            elif counterpart.account_id.account_type in ['equity', 'liability_non_current']:
                financing_cash_flow += cash_amount
    
    return {
        'operating': operating_cash_flow,
        'investing': investing_cash_flow,
        'financing': financing_cash_flow,
    }
```

## 关键技术点

### 1. 现金账户识别

```python
CASH_ACCOUNT_TYPES = [
    'asset_cash',       # 库存现金、银行存款
    'asset_current',    # 其他货币资金（支付宝、微信等）
]
```

### 2. 现金流量分类规则

| 现金方向 | 对方科目类型 | 分类 | 示例 |
|---------|------------|------|------|
| 流入 | asset_receivable | 经营 | 客户付款 |
| 流入 | income/income_other | 经营 | 收到服务款 |
| 流出 | expense/expense_direct_cost | 经营 | 支付地接费 |
| 流出 | liability_payable | 经营 | 支付供应商 |
| 流出 | asset_fixed | 投资 | 购买车辆 |
| 流入 | asset_fixed | 投资 | 处置固定资产 |
| 流入 | equity | 筹资 | 股东投资 |
| 流入 | liability_non_current | 筹资 | 长期借款 |
| 流出 | liability_non_current | 筹资 | 偿还长期借款 |

### 3. 勾稽关系验证

```
期末现金 = 期初现金 + 经营净现金流 + 投资净现金流 + 筹资净现金流 + 汇率影响

资产负债表：
  货币资金（期末） = 现金流量表：期末现金及现金等价物
```
