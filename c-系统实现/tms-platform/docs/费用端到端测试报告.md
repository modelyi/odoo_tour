# 费用端到端测试报告

**日期**: 2026-09-17  
**测试类型**: 端到端集成测试  
**测试范围**: 费用录入 → 会计分录 → 三大报表

---

## 测试目标

验证费用业务从录入到三大报表的完整流程：

1. **费用录入**：创建费用凭证（现金支付、应付账款）
2. **会计分录**：验证凭证借贷平衡
3. **利润表**：验证费用正确反映
4. **资产负债表**：验证现金/应付变化
5. **现金流量表**：验证现金流出分类
6. **三表勾稽**：验证报表间一致性

---

## 测试场景

### 场景 1: 导游报销差旅费（现金支付）

**业务描述**: 导游完成团队后报销差旅费 3,000 元，以现金支付

**会计分录**:
```
借：主营业务成本 - 差旅费    3,000
  贷：库存现金                3,000
```

**预期影响**:
- 利润表：费用增加 3,000，净利润减少 3,000
- 资产负债表：现金减少 3,000
- 现金流量表：经营活动现金流出 3,000

### 场景 2: 地接社费用（应付账款）

**业务描述**: 收到地接社服务费账单 15,000 元，尚未支付

**会计分录**:
```
借：主营业务成本 - 地接费   15,000
  贷：应付账款 - 地接社      15,000
```

**预期影响**:
- 利润表：费用增加 15,000，净利润减少 15,000
- 资产负债表：应付账款增加 15,000
- 现金流量表：无影响（未涉及现金）

### 场景 3: 办公费用（银行支付）

**业务描述**: 购买办公用品 2,000 元，以银行转账支付

**会计分录**:
```
借：管理费用 - 办公用品      2,000
  贷：银行存款              2,000
```

**预期影响**:
- 利润表：费用增加 2,000，净利润减少 2,000
- 资产负债表：现金减少 2,000
- 现金流量表：经营活动现金流出 2,000

## 报表结构验证

### 利润表结构 ✅

```
收益与损失 (sign=-1)
├── 收入 (sign=-1)
│   ├── 毛利润 (sign=1)
│   │   ├── 营业成本 (expense_direct_cost, sign=1)
│   │   └── 营业收入 (income, sign=1)
│   └── 其他收入 (income_other, sign=1)
└── 费用 (expense, sign=-1)
```

**验证结果**:
- ✅ 结构完整
- ✅ 符号配置正确
- ✅ 费用类账户正确映射

### 资产负债表结构 ✅

```
资产负债表 (sign=1)
├── 资产 (sign=1)
│   ├── 流动资产 (sign=1)
│   │   ├── 货币资金 (asset_cash, sign=1)
│   │   ├── 其他流动资产 (asset_current, sign=1)
│   │   ├── 应收账款 (asset_receivable, sign=1)
│   │   └── 预付账款 (asset_prepayments, sign=1)
│   └── 非流动资产 (sign=1)
│       ├── 固定资产 (asset_fixed, sign=1)
│       └── 其他非流动资产 (asset_non_current, sign=1)
├── 负债 (sign=-1)
│   ├── 流动负债 (sign=-1)
│   │   ├── 应付账款 (liability_payable, sign=-1)
│   │   ├── 信用卡 (liability_credit_card, sign=-1)
│   │   └── 其他流动负债 (liability_current, sign=-1)
│   └── 非流动负债 (sign=-1)
│       └── 长期负债 (liability_non_current, sign=-1)
└── 所有者权益 (sign=-1)
    ├── 实收资本 (equity, sign=-1)
    ├── 未分配利润 (equity_unaffected, sign=-1)
    └── 报告利润（亏损）(→ P&L, sign=-1)
```

**验证结果**:
- ✅ 结构完整（20 个节点）
- ✅ 覆盖所有 13 个账户类型
- ✅ 符号配置正确（资产=1，负债/权益=-1）
- ✅ 链接利润表（报告利润）

### 现金流量表结构 ✅

**核心逻辑**: 基于会计分录的直接法分析

**分类规则**:
- 现金 ↔ 收入/成本/费用 = 经营活动
- 现金 ↔ 应收/应付 = 经营活动（营运资金变动）
- 现金 ↔ 固定资产 = 投资活动
- 现金 ↔ 股权/长期负债 = 筹资活动

**验证结果**:
- ✅ 核心逻辑已重构（直接法）
- ✅ 支持按对方科目分类
- ✅ 支持明细下钻

## 三表勾稽关系验证

### 勾稽 1: 利润表 → 资产负债表

```
利润表：净利润 = 收入 - 成本 - 费用

资产负债表：
  未分配利润（期末） = 未分配利润（期初） + 净利润
  报告利润 = 利润表：净利润
```

**验证公式**:
```
资产负债表：报告利润 = 利润表：净利润
```

### 勾稽 2: 资产负债表 → 现金流量表

```
资产负债表：货币资金（期末） - 货币资金（期初） = 现金净增加额

现金流量表：
  经营净现金流 + 投资净现金流 + 筹资净现金流 = 现金净增加额
```

**验证公式**:
```
资产负债表：货币资金变化 = 现金流量表：现金净增加额
```

### 勾稽 3: 费用 → 三表联动

```
费用增加 20,000
    ↓
利润表：净利润减少 20,000
    ↓
资产负债表：未分配利润减少 20,000
    ↓
现金流量表：
  - 现金支付 5,000 → 经营现金流出 5,000
  - 应付增加 15,000 → 无现金影响
```

**验证公式**:
```
费用增加 = 现金减少 + 应付增加
20,000 = 5,000 + 15,000 ✓
```
