# 报账附件上传功能实现说明

## 功能概述

为导游门户的报账功能添加了附件上传能力，导游可以在创建报账单时上传发票、收据等证明文件。

## 实现内容

### 1. 前端表单增强 (portal_pages.xml)

**新建报账表单** (第 653-730 行)
- 添加 `enctype="multipart/form-data"` 属性支持文件上传
- 新增附件上传字段，支持多文件选择
- 支持格式：图片、PDF、Word、Excel
- 添加格式提示

**报账详情页面** (第 561-634 行)
- 新增附件列表卡片，显示所有已上传附件
- 每个附件显示：文件名、大小、上传时间
- 提供下载链接

### 2. 后端控制器更新 (portal.py)

**创建报账单** (第 319-341 行)
```python
# 处理附件上传
files = request.httprequest.files.getlist('attachments')
if files:
    Attachment = request.env['ir.attachment'].sudo()
    for file_storage in files:
        if file_storage.filename:
            Attachment.create({
                'name': file_storage.filename,
                'datas': file_storage.read(),
                'res_model': 'hr.expense',
                'res_id': expense.id,
                'type': 'binary',
            })
```

**查看报账详情** (第 277-292 行)
- 查询关联的附件记录
- 按创建时间倒序排列
- 传递给模板渲染

**下载附件** (第 294-308 行)
- 新增路由：`/my/guide/expenses/<expense_id>/attachment/<attachment_id>`
- 验证用户权限（只能下载自己报账的附件）
- 生成访问令牌并重定向到下载链接

### 3. 安全规则 (ir_rule.xml)

**附件访问控制** (第 57-70 行)
```xml
<record id="rule_attachment_portal" model="ir.rule">
    <field name="name">ir.attachment: portal user sees own expense attachments</field>
    <field name="model_id" ref="base.model_ir_attachment"/>
    <field name="domain_force">[
        ('res_model', '=', 'hr.expense'),
        ('res_id', 'in', user.partner_id.id and env['hr.expense'].sudo()._search(['|',
            ('x_guide_id.partner_id', '=', user.partner_id.id),
            ('employee_id.user_id.partner_id', '=', user.partner_id.id)]) or [])]</field>
    <field name="groups" eval="[(4, ref('base.group_portal'))]"/>
    <field name="perm_read" eval="True"/>
    <field name="perm_write" eval="True"/>
    <field name="perm_create" eval="True"/>
    <field name="perm_unlink" eval="False"/>
</record>
```

确保门户用户只能访问自己报账单的附件。

## 使用流程

1. 导游登录门户
2. 进入"我的报账" → "新建报账"
3. 填写报账信息
4. 在"附件上传"字段选择一个或多个文件
5. 提交报账
6. 在报账详情页查看已上传的附件
7. 点击附件名称下载

## 技术要点

- 使用 Odoo 的 `ir.attachment` 模型存储附件
- 附件通过 `res_model` 和 `res_id` 关联到报账单
- 文件内容以 base64 编码存储在 `datas` 字段
- 下载时使用访问令牌确保安全性
- 支持多文件上传（HTML5 multiple 属性）
- 文件大小限制由 Odoo 配置决定（默认 10MB）
